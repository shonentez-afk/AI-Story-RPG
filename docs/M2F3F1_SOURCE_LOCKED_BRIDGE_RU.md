# M2f3f1 — source-locked gate из Z.ai M2f3e в независимый M2c

Дата: 2026-11-04. Исходная ветка: `main` после очистки артефактов; код этапа в `feature/m2f3f1-source-locked-bridge-ru-grimm-20261104`.

## Что изменено

- Новый `apps/story_reader/lib/zai_m2c_source_bridge.dart`: только локальная проверка и построение `IntermediateStoryBlueprint` с редакторским текстом. Нет записи сохранений, публикации, установки BookWorld, облачных вызовов, ключей и скрытого перевода `keepForReview` в канон.
- Точная независимая M2c цитата для каждого исходного события: `chunkId`, абсолютные диапазоны UTF-16, SHA-256 текста, тип event, status confirmed, spoilerGate chapter, ограничение по главе. Совпадения названия, предложения без точных границ или имени героя недостаточно.
- Вторая независимая проверка `SourceSemanticCatalog` и `SemanticEditorialReviewSession`: `canonCandidate`, narratorCandidate, affirmative, textOrderOnly. Альтернативные авторские сцены строго отделены от исходных сцен и не получают вымышленных `assertionIds`.
- Права только `privateUse`, отдельное явное согласие, завершённые окна, редакторские решения, отсутствие открытых споров, неподтверждённых NPC и переходов в будущие главы; M2c causal preflight выполняется штатным движком.
- Если всё прошло — выдаётся исключительно **готовый к дальнейшей частной компиляции M2c-черновик** (`canStageForPrivateCompiler`). `canPublishBookworld`, `canDistributePublicly`, `canStartPlayableRpg`, `canSendToCloud` остаются ложными. Чтобы установить и играть, ещё необходим отдельный M2f3f2, подключающий `NativePrivateBookworldCompiler` после дополнительной проверки сценария и NPC.

После CI: интегрировать в UI подготовку этой схемы, редактор явных соответствий, экспорт M2c draft и только затем `NativePrivateBookworldCompiler`, проверить импорт .bworld, настоящую кампанию, 20+ ходов CLASSIC и физический Android/Windows.
