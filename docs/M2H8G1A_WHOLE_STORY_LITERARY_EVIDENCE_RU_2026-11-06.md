# M2h8g1a — локальная проверяемая карта литературных свидетельств всей RPG

Дата: 2026-11-06. Реализация: PR #111, отдельная ветка до exact-head CI и слияния.

## Реально добавлено

- Новый Dart-модуль **apps/story_reader/lib/whole_story_literary_evidence_manifest.dart**. Принимает индекс исходной книги, проверенную модель событий и один StoryPlan; по необходимости — исходный SourceEvidenceGraph для смысловых утверждений.
- Заново проверяет источник, UTF-16-диапазоны всех цитат и структурную валидность StoryPlan. Считает **все** достижимые пары «сцена + флаги» (до 2500) и переходы (до 10000), записывает кратчайший путь до каждого перехода и две законченные ветки к разным концовкам.
- Отдельно считает предложенные события книги и события, действительно задействованные достижимой игрой. Недоступные решения и неохваченные события сохраняются в отчёте — **нет** ложного утверждения, что весь литературный смысл книги был прочитан или перенесён в игру.
- Пакет не содержит полного текста книги или API-ключа. Есть ID события, позиции, SHA цитаты, SHA плана, SHA всего отчёта. Метод verifyUnchanged() отвергает изменение исходника/плана/содержимого.
- Если NarrativeBookModel содержит NarrativeClaim, без исходного графа evidence сборка запрещена. Для narratorCandidate, reported и uncertain явно разные типы НЕПОДТВЕРЖДЁННЫХ утверждений; точная цитата не доказывает владение, мотивацию, время, идентичность NPC или CANON.
- Нет сетевого запроса, изменений сохранения/SQLite, изменения .bworld или автоматического разрешения публикации. Это **подготовка данных для независимой литературной проверки**, а не сама литературная проверка.
- Синтетическая регрессия: две ветки, отключённый выбор, неохваченная глава, изменение редакции и SHA; отдельно — речь NPC о владении предметом с настоящим дословным диапазоном.

## Дополнительные идеи и приоритет

1. **P0 — независимая литературная проверка с provenance**: каждый факт помечать как предложение рассказчика, реплику NPC, убеждение героя, событие игры или UNKNOWN. Сверять мотивацию, чужие знания, обещания, предметы, флешбеки по двум завершённым веткам, не считать галочку пользователя литературным доказательством.
2. **P0 — ограниченное точечное исправление**: отдельный ИИ-критик возвращает точные проблемные scene_id/choice_id/source_event_id; ИИ-редактор исправляет только соответствующую прозу либо предлагает новый *частный* сюжетный переход; новый SHA и полный повторный аудит обязателен. Лимиты API и согласие видимы.
3. **P0 — настоящий CANON/ALTER_FATE и выбор героя**: у CANON не выдумывать обязательную вторую концовку, у ALTER_FATE ветка после отказа должна отличаться по последствиям; персонаж не может знать сведения до раскрытия.
4. **P1 — качество игровых выборов**: считать решение содержательным только если оно меняет доступные ситуации, предметы/знания, отношения или исход, а не цвет/формулировку текста. **Не дублировать** реализацию E6a PR #110 во внешнем генераторе: выработать один совместимый отчёт.
5. **P1 — карта покрытия исходника**: в обычном мастере показывать «найдено N событий / использовано M / не охвачено K», явно отделяя детектирование от смыслового понимания; подробные ID раскрывать в «Дополнительно».
6. **P1 — воспроизводимая приёмка**: сериализованный путь выборов и SHA состояния на каждом шаге, включая рестарт приложения, автономное прохождение, перенос на другое устройство и E2E двух отличающихся FB2.
7. **P2 — адаптивный объём**: короткая сказка и длинный роман требуют разных границ сцен/пакетов, но не скрытого увеличения оплачиваемых GLM-запросов. Сначала обеспечить корректный первый образец без названия в условиях кода.

## Что делать следующим

**M2h8g1b:** поверх манифеста сформировать ограниченные по тексту consent-окна, выводить точный русский контекст до оплачиваемого вызова GLM, отделять литературные замечания от догадок, требовать sourceID/choiceID и возвращать UNKNOWN при неполноте источника. Не писать CANON в .bworld. Проверить checkpoint/retry без новой оплаты. Затем M2h8g1c — единый отчёт по всем пакетам и всем маршрутам.

**M2h8g2:** исправлять только проверяемые проблемные места и обязательно повторно запускать g1a/g1b. После — CANON/ALTER_FATE, главный мастер «книга → герой/режим → играть», настоящие GLM E2E на двух FB2 и QA на Windows/Android.

## Ограничения первого этапа

Модуль только локальный; не выбирает литературную интерпретацию и не доказывает ни одну реплику/мотив NPC. Индексирование всей книги не равно покрытию её игровых событий. Если предел состояний или размера достигнут — явный отказ, а не обрезание данных и ложное «всё проверено». Пользовательских старых игровых кампаний для миграции нет.
