# M2f2c — название книги и русский язык предложений Z.ai

Дата: 2026-11-03. База `main` `91573e9d04a76a4c5fa49dc76bfdfdccb4d505e9`, релиз `test-build-397`. Статус **CODE / CI PENDING** до полного exact-head CI/M0/Windows/Android и ручной проверки. Код книги и игровой движок не менялись.

## Почему меняем

В `test-build-397` пользовательский фрагмент отправлялся в GLM-4.7-Flash **без названия книги**. `systemPrompt` уже предлагал писать `label` и `uncertainty` по-русски, но формальная проверка языка отсутствовала: мог появиться `Start of the story`. Цитатный якорь сам по себе подтверждает точность источника, **не** сюжетную ценность.

## Что реализовано

- На странице «Предложения ИИ по цитатам» явно отображается название из локального `BookSourceIndex.title` (из FB2/TXT) и пояснение: **описания — по-русски; цитаты и имена собственные — без перевода**.
- Диалог разрешения перед **каждым выбранным фрагментом** показывает точное название книги и полный текст этого фрагмента. До подтверждения данные не отправляются. Автор, другой текст книги, игровой прогресс, путь к файлу, fingerprint и прочие метаданные остаются локально. Модель получает дополнительное поле **`book_title`**, но только если вызывающий код явно передал `consentForBookTitle: true`. Для старых вызовов значение по умолчанию `false` — одно согласие на текст не раскрывает название автоматически.
- При передаче названия оно валидируется: непустое, не больше 240 UTF-16 символов / 1024 UTF-8 байтов. Точный текст не сокращается без уведомления и не записывается в лог; при превышении запрос блокируется до сети.
- И название, и отрывок передаются как JSON-данные внутри user message, **не** как system instruction. Промпт прямо определяет их недоверенными и запрещает выводить факты из внешних пересказов и памяти модели. Книга, показанная в контексте, **не считается доказательством** без точной цитаты выбранного отрывка.
- Более строгий русский промпт: `label` и `uncertainty` должны быть на русском; `quote` не переводится и должен дословно совпадать с исходником. Ключи JSON и машинные категории остаются английскими по контракту.
- Локальная языковая проверка для пользовательских подписей: описания должны содержать преимущественно кириллицу (проверка пропорции кириллицы и латиницы). Исключение только для дословных иностранных **имён персонажей и географических названий**, которые действительно содержатся в оригинальной цитате. Английские описания событий и фактов отбрасываются. Виджет показывает число находок, отклонённых из-за языка. Русский язык не доказывает истинность: исходная цитата, статус `INFERRED` и ручная проверка обязательны.
- Передача **того же самого** названия + фрагмента при bounded 429/network retries остаётся строго в рамках единого пользовательского согласия из M2f2b (не более трёх идентичных попыток); нет отправки другого фрагмента, background batch, платного fallback или автоматического включения в BookWorld.
- Никакого изменения `SQLite/.bwsave`, checkpoints, миров, сцен, оригинального текста книги или исторических данных кампаний.

## Тесты

- `apps/story_reader/test/zai_semantic_language_title_test.dart`: default-privacy без title; отдельный флаг consent передаёт только название и exact source excerpt; title injection остаётся только user data; превышение длины блокирует сеть; retries сохраняют идентичный payload; English label/uncertainty отклоняются; русские описания принимаются; англоязычные имена в английской книге не переводятся.

Свободная RPG и полноценное адаптирование книги остаются отдельными этапами.
