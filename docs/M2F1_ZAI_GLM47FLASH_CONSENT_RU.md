# M2f1 — Z.ai / GLM-4.7-Flash: безопасное подключение

Дата: 2026-11-03. База: main c1e2b659ef07abb08427a18e5f818994b7312247. Статус: CODE / EXACT-HEAD CI PENDING. Это подготовка интерфейса и ручного теста, не готовый игровой ИИ.

## Провайдер и контракт API

- Ключ: https://z.ai/manage-apikey/apikey-list (Standard API Key, не Coding Plan).
- Endpoint: POST https://api.z.ai/api/paas/v4/chat/completions, HTTPS + Bearer.
- Модель: glm-4.7-flash; платные glm-4.7 / glm-4.7-flashx НЕ используются и не включаются автоматически.
- На 2026-11-03 официальная таблица https://docs.z.ai/guides/overview/pricing отмечает GLM-4.7-Flash как Free по входу, кешу и выходу. Условия и лимиты могут измениться: https://z.ai/manage-apikey/rate-limits.
- Документация: https://docs.z.ai/api-reference/llm/chat-completion.
- Проверка: thinking disabled, max_tokens 48, stream false, одна синтетическая фраза. Ни web search, ни tools, ни пользовательских данных.

## Что будет в приложении

Маршрут: Главное меню → Настройки → ИИ: Z.ai · GLM-4.7-Flash.

1. Скопировать адрес создания ключа.
2. Ввести ключ в скрытое поле, сохранить в OS-protected flutter_secure_storage; поле очищается, сохранённое значение не показывается.
3. Включить разрешение на единственную ручную сетевую проверку через отдельный диалог согласия. По умолчанию разрешение выключено.
4. Нажать «Проверить соединение»; только эта кнопка отправляет короткий технический текст, ни одной книги, NPC или сохранения.
5. Отключить соединение, оставив ключ, либо подтвердить удаление ключа. Замена ключа снимает прежнее разрешение.
6. 401/403/429/5xx, ошибки сети и таймаут показываются без тела ответа, содержимого запроса и API-ключа.

## Инварианты безопасности

- Ключ не хранится в SharedPreferences/файлах/SQLite/кампаниях/.bwsave/логах/GitHub. Там есть только булево значение разрешения.
- Никакой автоматической отправки текста книги или создания канона. Интеграция с BookWorld/игровым движком НЕ включена.
- HTTPS endpoint фиксирован, произвольные хосты и редиректы запрещены; автоматических платных fallback и бесконечных повторов нет.
- Нет фоновой активности при запуске, открытии книги или сохранении настроек. Новое согласие на конкретную книгу потребуется в M2f3.
- На Android генерируемый CI host получает permission INTERNET, allowBackup=false, usesCleartextTraffic=false через tools/configure_android_ai_host.py. Если защищённое хранилище недоступно, нельзя переходить на plaintext.
- Реальные API-ключи нельзя прикреплять к чату, задачам, тестам или коммитам.
