# M2e5b3b2a — причинная проверка знаний NPC в приватном BookWorld

**Дата:** 2026-11-03. **База:** `main` `08c676662b28f168040d8c62c3e146e2208c8fca`, последний релиз `test-build-339`.
**Статус:** рабочая ветка; CODE, exact-head CI ожидается. **Не считать принятым без полного PASS.**

## Цель и фактически добавленное

Перенесён ранее сохранённый офлайн-патч M2e5b3b2 в отдельную ветку. Точечно заменён `PrivateBookworldImporter._causality` без изменения `StoryBlueprint`, `StoryWorld` и форматов сохранений.

- Строго типизированы допустимые условия (`flag_is`, `knows_fact`) и эффекты (`set_flag`, `learn_fact`); остальные операции в приватной RPG запрещены.
- Все правила, включая в условно недостижимых сценах, проходят предварительную проверку.
- Состояние причинности содержит `(scene, flagBits, knowledgeBits)`, где `knowledgeBits` — `BigInt` по парам «конкретный актёр → конкретный факт». Получение факта одним NPC не превращается в знание другого или игрока.
- Условие `knows_fact` проверяется **до** игрового выбора, результат `learn_fact` применяется **после** него. Требуются реальные достижимые пути к обеим концовкам, отсутствие безвыходных тупиков и возможность завершить игру из каждого состояния.
- Непрозрачные `npc_<hash>`/`fact_<hash>` ID, пустые начальные знания, подтверждённый переход для каждого факта и каждого используемого `knows_fact`, предохранитель 2500 состояний.
- Старые миры только с флагами используют ту же семантику при `knowledgeBits=0`. Книги, SQLite, `.bwsave`, существующий редактор и компилятор M2e5b3b1 не мигрируются.

## Проверка

Новый `packages/bookworld_format/test/private_knowledge_reachability_test.dart` проверяет старый классический формат, запрет `help` до получения знания, независимость знаний игрока/NPC, детерминированный журнал 120 ходов с replay/hash, порчу истории, начальное раскрытие секретов, попытку использовать знание другого актёра, неподдерживаемое условие, невозможную концовку и рост пространства состояний более 2500.

**Приёмка:** Dart/Flutter analyze, полный Dart/widget suite, Python/schemas, M0, Windows portable, Android APK — на одном exact HEAD. До получения результатов не сливать PR.
