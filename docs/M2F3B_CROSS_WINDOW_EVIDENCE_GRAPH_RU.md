# M2f3b — сквозной граф проверяемых цитат, осторожное объединение и причинные гипотезы

## Изменения

- `zai_cross_window_evidence_graph.dart`: строится детерминированная **локальная** сводка **только** по source-backed предложениям Z.ai с ручной пометкой `keepForReview`. `rejected` и нерассмотренные отклоняются от сводки. Нет новых сетевых запросов, автор не передаётся, старый `m2f3a` checkpoint не мигрируется и не меняется.
- Отдельные сущности `ZaiAnchoredFinding`: original `candidateId`, точная `quote`, `chunkId`, UTF-16 offsets, глава/исходный блок/окно и статус `INFERRED` у кандидата; цитата вновь проверяется валидатором. Объединение имён — **только группировка одинаковых написаний** (trim, case-fold, пробелы) и одного типа в **разных смысловых окнах**, без объявления тождества и без агрессивных падежных/фонетических правил. Одноимённые герои и алиасы не объединяются автоматически.
- Повествовательные события выводятся в **порядке текста**, но это **НЕ** внутренняя хронология мира книги: флэшбэки, ложные сообщения, диалоги и повторения событий ещё не распознаны. События с одинаковой подписью в разных окнах не схлопываются. `fact` / `state` видны отдельно, без объявления объективными истинами.
- `ZaiCrossWindowLinkNotebook`: пользователь может сохранить два вида явно *неподтверждённых* связей между точными цитатами: `possibleIdentity` (имена/места одного типа, разные окна) и `possibleCause` (два события из разных окон, прямая направленность по порядку текста, без истинности сюжета). Каждая связь подписана `EDITORIAL_HYPOTHESIS` и `canPublishBookworld=false`. У причинной гипотезы и именованного совпадения отдельный флажок подтверждения по умолчанию OFF. Исходные решения редактора обязательны для обоих концов.
- Связи сохраняются в независимой папке `SourceCheckpointScope.zaiCrossWindowLinks`, предел 256 KiB / 800 ссылок, исходный fingerprint, SHA-256 и validation исходных цитат и двух ручных решений. Если прежняя связь перестала соответствовать текущим сохранённым кандидатам (перепроверка окна, отзыв редактора, смена редакции), старый checkpoint **не перезаписывается**, блокируется и предлагается отдельный подтверждаемый сброс **только связей**. Игровые сейвы, книги, промпты Z.ai и M2f3a не трогаются.
- Новый экран `ZaiCrossWindowReviewPage` доступен из проверки смысловых окон кнопкой **«Сводка персонажей, событий и связей»**. Перечень повторов имён, исходные цитаты и переход в конкретное окно, события по порядку текста, отдельные состояния и факты, создание/отзыв ссылок, постраничное раскрытие десятков/сотен элементов. Просмотр этой страницы никогда не инициирует сеть. Нельзя создавать BookWorld.
- Устранена непоследовательность M2f3a: если запись нового результата не удалась, страница не показывает его как уже сохранённый и не разрешает пометить его как сохранённую находку.

- `zai_cross_window_evidence_graph_test.dart`: разные главы и окна, `Кай`/форма `кай`, безопасная группировка по точному написанию, исключение отклонённых и ещё нерассмотренных кандидатов, повторные события, строгие UTF-16 якоря, причинная гипотеза только между двумя оставленными событиями, запрет обратной/внутри-оконной связи, SHA/foreign-edition/tamper и отзыв ручного решения.

## Ограничения / следующий шаг

Это первый устойчивый сквозной обзор. **НЕ ГОТОВО**: доказанное разрешение местоимений, алиасов/падежей, знания NPC, истинная сюжетная хронология, достоверная причинность, фиксация конфликтующих версий рассказчика, автоматическая обработка всех окон без отдельного согласия, автоматическая компиляция игрового канона. Дальше M2f3c: многошаговая ручная ревизия событий/отношений с оценкой противоречий и source-backed preflight графа. После этого M2f4: строгая сцена/ветвление/свободный ввод ИИ.
