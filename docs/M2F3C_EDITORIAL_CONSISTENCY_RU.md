## Что добавлено

1. **`zai_editorial_consistency.dart`** — детерминированные источниковые подсказки и отдельный блокнот ручных вопросов. Используются только кандидатские цитаты из текущей `ZaiCrossWindowEvidenceGraph`, которые пользователь ранее пометил `keepForReview`. ИИ заново не вызывается, отдельные согласия и retry M2f3a не меняются.
2. Автоподсказка **«возможное расхождение»**: две цитаты типа `fact`/`state` с одинаковыми словами (нормализация только регистра, «ё», нескольких знаков пунктуации и пробелов), но с наличием/отсутствием отдельной частицы `не` / `not`. Не более 120 подсказок в порядке исходного текста. Само совпадение **НЕ доказывает противоречие**: может быть разное время, говорящий, неверный слух, отрицание с иной областью действия. Русские падежи, синонимы и местоимения здесь НЕ автоматически разрешаются. При отсутствии точного сопоставления никаких догадок нет.
3. **Четыре ручных вопроса** между двумя точными cite-ID: `possibleAlias` (разные имена одного типа `character` или `location`), `possibleDiscrepancy` (два `fact`/`state`), `possibleRelationship` (два разных `character`), `possibleBefore` (два `event`). В обратном порядке относительно текста можно предложить временное отношение, но **оно всё равно не подтверждено**. Предложения хронологии не могут образовывать прямые или транзитивные циклы. Все вопросы имеют статус `OPEN_EDITORIAL_QUESTION` и `canPublishBookworld=false`.
4. **`ZaiEditorialConsistencyNotebook`** сохраняет только IDs двух исходных находок, тип и локальное объяснение редактора длиной 8–240 символов. Не сохраняет полную книгу, авторство, ключи или API-ответы; source fingerprint и SHA-256 защищают от перепутанного файла, а IDs снова сверяются с актуальными `keepForReview` находками. При отзыве цитаты или смене редакции прежний блокнот отклоняется **целиком**, без невидимого удаления отдельных вопросов и без перезаписи. Лимит 600 вопросов / 512 KiB. Устаревший файл можно сбросить лишь по отдельному согласию и **только** для папки M2f3c.
5. **`zai_editorial_consistency_page.dart`** — отдельный офлайн-экран, доступный из «Сводка персонажей, событий и связей» кнопкой «Проверить алиасы, противоречия и хронологию». Список осторожных подсказок, цитаты с главой/окном и кнопкой перехода к исходному окну, категории ручных вопросов, фильтр по имени/словам, по 60 кандидатов на одной странице выбора (выбранные не теряются), обязательное текстовое обоснование и дополнительный пустой по умолчанию checkbox в диалоге с **двумя оригинальными цитатами**. В блокноте можно открыть и удалить любой вопрос. Есть явный сброс только M2f3c при повреждении файла. `ZaiSemanticPreviewPage` и `ZaiCrossWindowReviewPage` получают optional repository injection для независимых виджет-тестов.
6. **НЕТ** автоматического тождества персонажей, доказанного родства, лексического вывода объективных состояний, сюжетного календаря/истинной причинности, изменения `BookWorld`, игровых сохранений и сетевой передачи. Старые checkpoint M2f3a/M2f3b остаются byte-compatible; новый `SourceCheckpointScope.zaiEditorialConsistency` живёт в отдельном каталоге.
