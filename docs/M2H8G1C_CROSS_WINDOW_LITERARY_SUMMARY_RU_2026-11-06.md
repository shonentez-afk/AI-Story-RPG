# M2h8g1c — единый итог литературной рецензии всех пакетов

Дата: 2026-11-06. Статус: код в отдельном PR до exact-head CI.

## Реализовано

Добавлен чистый локальный Dart-модуль `WholeStoryLiterarySummary`. Он **не отправляет запросы** и принимает только полный набор сохранённых результатов M2h8g1b, сверенных с точными `LiteraryReviewWindow` исходной книги и текущего StoryPlan.

- `compile(manifest, reports)` заново вызывает `manifest.verifyUnchanged()` и восстанавливает каждый `WholeLiteraryReviewReport` из строгого JSON относительно своего окна. Пропущенные, переставленные, чужие или изменённые результаты запрещены.
- Сводятся число проверенных пакетов/переходов, количество замечаний и их виды, требующие исправления пакеты, пакеты с неизвестным литературным смыслом, неиспользованные исходные события книги.
- Повторяющееся утверждение об одном выборе и типе проблемы, пришедшее из двух отдельных окон, выделяется в `CROSS_WINDOW_REVIEW_REQUIRED`. Отличия в уровне опасности и ссылке на литературное событие показываются как *поводы для редакторской проверки*, не как автоматически доказанная ошибка.
- Выдаётся воспроизводимый SHA-256 итогового отчёта; оригинал книги, полные цитаты и ключ API в результат не копируются.
- На существующем экране «Проверка логики всей истории» блок «Итог всей проверки» появляется только после завершения всех пакетов. Нет кнопки «подтвердить CANON» или скрытого изменения игровой кампании.
- Регрессия проверяет полный синтетический многооконный сценарий (20 переходов, 3 пакета), отклонение неполного набора, переставленных пакетов, детерминированную контрольную сумму и отсутствие полномочий менять BookWorld.

## Ограничения и честная граница

1. Нет независимого доказательства литературного CANON, даже если ИИ выдал ноль замечаний. Реплики NPC, мотивация, знания, владение и хронология по-прежнему требуют проверяемых свидетельств и независимого редакторского решения.
2. Этот первый итог объединяет *повторяющиеся проблемы* между окнами. Он **пока не выводит новые логические противоречия из сопоставления разных утверждений**, не решает литературные неоднозначности и не подтверждает взаимосвязь всех художественных диалогов.
3. Существующий M2h8g1a знает состояние флагов по всем путям, но не доказывает, что GLM правильно поняла все важные события книги. Неохваченные события указываются отдельно.
4. Автоматическое исправление, настоящий выбор героя, CANON/ALTER_FATE, проверка двух реальных различных FB2 на устройствах — следующий этап.
5. Нельзя использовать личные книги, API-ключи или непубличные результаты в GitHub Actions. Нет старых пользовательских кампаний, требующих миграции.
