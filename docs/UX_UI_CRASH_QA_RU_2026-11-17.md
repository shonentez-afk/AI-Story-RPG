## Исправления и технические причины

1. `WorldPlayPage._reload` больше не очищает уже показанную проверенную сцену при временном сбое повторного чтения SQLite: остаётся последняя успешно загруженная сцена с панелями, ошибка — в SnackBar; первоначальная загрузка с ошибкой показывает retry.
2. Добавлен `apps/story_reader/test/ux_crash_resilience_test.dart` с регрессиями двойного ввода, ошибками, открытием/закрытием страниц, панели и малым экраном.
3. Flutter SDK закреплён на **3.47.9** во всех CI билдерах из-за несовместимого перехода stable на 3.50.0 и массовых диагностик deprecated `material.dart`. Это временная воспроизводимая база; миграция SDK — отдельно.
4. В `windows_qa_mcp` добавлен `qa_crash_events`: чтение ограниченных событий Application Error ID 1000 **только с точным путём** `ai_story_reader.exe`; не заменяет Flutter/Dart exception logs.
5. Windows CI теперь создаёт не только EXE, но и реально запускает его, кликает главная→библиотека/новая история/прохождения, сохраняет PNG/JSON/MD. Отдельный offline UX job устраняет зависимость этой QA-проверки от внешнего книжного сайта.
6. Для полного книжного regression дополнен fail-closed pinned source mirror; сохранены требования 62 настоящих историй, минимум текста, таблица содержания, реальный SHA-256 манифест.

## Что ещё нельзя считать подтверждённым

- **Предыдущие вылеты пользователя не воспроизведены и не идентифицированы**: нет Event Viewer/Flutter логов с его ПК и шагов, которые вызывали отказ. Отсутствие событий на одноразовом CI runner не доказывает отсутствие ошибок на его Windows.
- GigaCode Desktop на пользовательском ПК и версия Python 3.15 не были подключены к данному тесту; нужен вызов `qa_status`, `qa_crash_events(hours=24)`, `qa_begin`, `qa_launch/qa_attach`, `qa_screenshot`, осторожное GUI-прохождение и `qa_report`. После каждого подозрительного вылета сопоставить логи и последнюю сцену.
- Реальный E2E двух русских FB2 с живым GLM, генерация/импорт всей книги, повторный запуск, сохранение/восстановление `.bwsave`, маршруты альтернативного сюжета, реальные NPC-диалоги на физическом Windows/Android — отдельная незакрытая пользовательская приёмка. Не объявлять завершённым Issue #118 только по синтетическим или CI тестам.
- На runner у правого края скриншота частично обрезаны элементы Windows-окна; вероятна разница экранного размера/позиции. Не считать доказанным дефектом Flutter до проверки на физическом экране и DPI.
