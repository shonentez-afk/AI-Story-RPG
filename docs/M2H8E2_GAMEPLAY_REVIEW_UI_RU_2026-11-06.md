# M2h8e2 — простой пользовательский мастер предметов и знаний

Дата: 2026-11-06. Статус: отдельная ветка поверх PR #102, не объединено с основной программой до CI.

## Новый UX

В существующей «Пробной RPG по развилке» после проверки двух цитат и согласия на частную игру появилась НЕОБЯЗАТЕЛЬНАЯ кнопка «Предметы и знания из книги».

1. Открывается экран с дословными цитатами выбранной редакции и решениями StoryPlan, которые в случае согласия будут отправлены GLM 4.7 Flash.
2. Без отдельной галочки на эти цитаты кнопка сетевого запроса недоступна. Пользовательский ключ не отправляется в тексте API запроса; временные ошибки повторяют те же байты максимум три раза. Повтор выполняет сервис PR #99.
3. Ответ ИИ отображает возможные item/fact и неопределённость. Можно ничего не выбирать или удалить выбранное; игра без предметов допустима. Для выбранного эффекта читатель пишет отдельную заметку, что это допустимая ИГРОВАЯ выдумка, не доказанный CANON.
4. При создании пробной игры сначала строится исходный проверенный v3, затем применяются только выбранные и прошедшие PR #100 эффекты, после чего требуется второе подтверждение точного пользовательского набора. Пакет заново компилируется в отдельный rich v3 с новой identity и действительно изменяемым инвентарём/знаниями. Затем пользователь явно устанавливает мир и создаёт новую кампанию.
5. Ранее созданные игры, архивы и SQLite-сохранения не переписываются; если пользователь закрыл диалог, создание нового мира отменяется. Без дополнительных предложений всегда действует прежняя проверенная логика.
6. Widget regression проверяет отсутствие HTTP до согласия, возврат выбранного предмета и запрет выдавать предложения сразу как эффект.

## Ограничения

Экран пока включён только в КОРОТКУЮ пробную RPG. Многоактовый процесс и автоматическое предложение всех предметов по всей книге, полноценная литературная критика, подтверждение мотивов/знаний NPC, выбор героя и CANON/ALTER_FATE ещё впереди. Также нужны локальные checkpoints и настоящее пользовательское тестирование на Android/Windows.

Результаты PR #102 и #103 должны проходить exact-head Python/Dart/Flutter/Windows/Android CI. Никаких частных книг/API-ключей в публичный CI.
