# M2e3 — проверка готовности личной RPG по установленному пакету

Дата: 2026-11-03. База: main 867b5816814a5bbb792fec56cd69dfc41f4dbd14, test-build-310.

## Что меняется

- В единой странице «Подготовка книги» есть отдельная карточка готовности из трёх независимых частей: проиндексированная книга, подготовленный человеком сценарий, **фактически установленный и проверенный** игровой пакет. Нельзя считать все эти состояния одним процентом.
- Проверка наличия игры выполняется по запросу. Она перечисляет локальные BookWorld, фильтрует кандидатов по префиксу SHA исходной книги, затем повторно проверяет ZIP, manifest, SQLite и происхождение через независимый `PrivateBookworldImporter` в isolate.
- Статус `privatePlayable` возможен только при полном совпадении source fingerprint, ID игрового мира и SHA архива с каталогом. Только тогда появляется кнопка «Открыть личную RPG» и используется уже существующий экран кампаний.
- Чужие, удалённые, повреждённые пакеты, а также более 32 кандидатов по одной книге не разблокируют игру. Ни пакет, ни сейвы проверка не изменяет. Нет отправки текста в облако.
- Отдельно обозначено, что экспериментальная ручная 3-сценная адаптация не равна RPG по всему роману. Текстовое покрытие не доказывает сюжетное.
- Старые импортированные книги, `.bwsave`, legacy M1.6, SQLite игры, записи редактора не мигрируются.

## Тестовый план и ограничения

Новый `private_game_readiness_test.dart` проверяет пустую библиотеку, сторонний мир, повреждённый ZIP, превышение ограничителя и отсутствие ложной кнопки старта. Старое UX-утверждение обновлено на новое точное название.
