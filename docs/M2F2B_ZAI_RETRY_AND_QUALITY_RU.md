## Диагностика

1. Android-фрагмент №3, глава 1, «Послушаем же, как было дело.» вернул формально source-anchored JSON `event / Start of the story`; это **метатекст рассказчика**, а не событие в мире книги. Цитата действительно встречается в источнике, но достоверность цитаты не равна смысловой ценности.
2. Android-фрагмент №2, глава 1, 732 байта: UI показал «Время ожидания Z.ai истекло. Проверьте сеть и повторите». Это точная строка `ZaiHttpTransport` из M2f1: соединение 10/12 секунд, ответные HTTP-заголовки 25 секунд, чтение потока при отсутствии данных 25 секунд; `ZaiSemanticPreviewService` дополнительно давал максимум 45 секунд на один запрос. Вполне возможно, что свободная модель/очередь не успевала вернуть первый ответ. **Нельзя утверждать, что пользователь получил HTTP 429 — скриншот этого не подтверждает**.

## Исправление

- Транспорт: подключение до **20 секунд**, начало ответа до **110 секунд**, отсутствие новых байтов до **45 секунд**, общий предел одной попытки предпросмотра **150 секунд**. Синтетическая проверка API-ключа в M2f1 по-прежнему ограничена собственными 40 секундами.
- При **разовом согласии на конкретный видимый фрагмент** допускаются максимум **3 последовательных HTTP-запроса** с идентичным телом, моделью `glm-4.7-flash` и фиксированным HTTPS endpoint. Первоначально один запрос; если нужен повтор, пользователь **не нажимает диалог согласия повторно**. Согласие не распространяется на соседние куски, новую книгу или будущий сеанс.
- Повторять только временные ситуации: обрыв/SocketException, HttpException, TimeoutException, HTTP 408, HTTP 429 (временная перегрузка/лимит частоты), HTTP 5xx. Паузы по умолчанию: ошибки сети/5xx 3 и 8 сек; HTTP 429 — 5 и 15 сек, либо доверенный `Retry-After` из HTTP-заголовка. Если сервер просит ждать больше **60 секунд**, остановить повтор и честно объяснить причину; не обходить лимит.
- Z.ai возвращает дополнительные business-коды в `{"error":{"code":"..."}}`: `1113` — недостаточный ресурс/баланс, `1302` — частота, `1305` — нагрузка, `1308…1321` — исчерпанные лимиты аккаунта или ограничения пакета. **Не повторять** `1113`, `1308…1321`, 400/401/403, TLS handshake, неверный JSON и галлюцинации. Официальная таблица: https://docs.z.ai/api-reference/api-code
- UI перед согласием прямо сообщает о возможных **до двух** дополнительных отправках того же текста. Во время операции показываются попытка 1/2/3 и ожидание. Кнопка **«Остановить дальнейшие попытки»** и выход со страницы запрещают ещё не отправленные повторы; уже отправлённый POST может продолжить обработку на стороне сервера. Поэтому возможен повторный расход лимита даже если прежний ответ потерялся. Нет бесконечного повтора и фоновой очереди.
- Качество смысловых событий: system prompt требует писать `label/uncertainty` по-русски, отличать событие внутри мира от вступительных слов рассказчика. Дополнительный локальный фильтр отвергает `event` с пометками `Start of the story / Introduction / Начало истории` и явными приглашениями слушать («Послушаем же…»). Общий признак **только** помогает, но не доказывает правильность остальных событий — обязательна ручная проверка канона.
- Никакие книги, исходные фрагменты, редакторы, SQLite, BookWorld или `.bwsave` не изменяются. Секретный ключ Z.ai остаётся в защищённом хранилище; запросы/ошибки никогда не записываются в лог.
