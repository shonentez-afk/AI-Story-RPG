# M2b4a — план интерфейса семантического провайдера (NEXT, не реализован)

Актуальная база: M2b3c PR #11 merged, кодовый SHA `4cad81c990d816cda6b316506ac47ce3fdee2967`; CI `41408023445` 6/6 PASS. Этот документ — план следующего функционального этапа, **не отчёт о реализованном ИИ**.

## Цель

После M2b3c есть лишь проверяемые цитаты, простые локальные шаблоны, решения редактора о предполагаемых личностях и неканоническом порядке глав. M2b4a должен добавить **сменяемый semantic-provider boundary** без зависимости игрового движка от конкретного LLM. Сначала интерфейс и безопасная локальная реализация/заглушка; реальный подключённый локальный/облачный ИИ — отдельная приёмка. Нельзя объявлять книгу автоматически играбельной.

## Предлагаемый порядок реализации

1. **SourceSemanticProvider / SemanticExtractionRequest / SemanticCandidateBatch**: типизированный интерфейс. Вход — normalized source fingerprint, список ограниченных source chunks, language/genre hints, requested extraction types и source evidence policy. Выход — строго типизированные кандидатные сущности/имена/alias/места, события, факты, состояния и их зависимости; обязательный exact source chunk id / UTF-16 offsets / quoted SHA; встроенная неопределённость и mode INFERRED. Никакой прямой записи в `BookWorld` или `CampaignStore`. Клиент отдельно вызывает validator, который вновь сверяет исходный индекс.
2. **Локальный режим по умолчанию**: не отправлять текст по сети. Разделить `OfflineRuleProvider` (уже принятые regex-кандидаты) и API будущего `LocalModelProvider` (без объявления установленной модели до проверки исполняемого пакета, лицензии, производительности). При отсутствии модели явно сообщать об ограниченном локальном анализе, не заменять его фиктивными ответами.
3. **Облачный режим — только после отдельного осознанного согласия для конкретного источника**: объяснить провайдера, объём текста, цель обработки, способы хранения/обработки, потенциальные ограничения приватности и возможность отмены до отправки. До подтверждения никаких сетевых запросов, телеметрии содержания или автопереключения из локального режима. Если облачный провайдер не настроен — опция недоступна без фальшивого «AI активен». Права пользователя на публикацию/переработку проверять отдельно через `rights_status`; согласие на анализ ≠ право публично распространять произведение.
4. **Полная fail-closed валидация**: проверять exact UTF-16 slice, Unicode surrogate, исходные главы/блоки, SHA/fingerprint, лимиты токенов/байтов, типы и допустимые enum, дубликаты, спойлеры и `INFERRED/CONFIRMED/CONFLICTED/REJECTED`. Не повышать уверенность по словам модели. Текст книги — недоверенные данные, его команды не могут менять системную логику, сетевую политику, пути сохранений или `rights_status`.
5. **Надёжное продолжение**: очередь по чанкам с checkpoint версии провайдера, модели, source fingerprint и состояния review в отдельной приватной директории; обработка порциями, отмена между порциями, атомарное сохранение прогресса до обновления UI. Нельзя удалять/перезаписывать checkpoints M2b1, M2b3b, M2b3c или игровые сейвы. Обязательны пределы памяти для длинных книг; при лимите остановка с объяснением.
6. **UX**: в уже существующей единой `Подготовке книги`, не новая библиотека и не вторая кнопка импорта. Предлагать выбор «Локально» / «Подключённый облачный провайдер» только после готовности реальной интеграции, до открытия потенциальных спойлеров показывать количество кандидатов, после открытия — точные цитаты, связи, подозрительные конфликты и причины отклонения.
7. **Схема coverage и переход к blueprint**: отдельно текстовое покрытие индекса, покрытие *извлечения* по проверенным категориям и доля вручную проверенных кандидатов. Никогда не считать одно за `gameplayCoverage`; до отдельного сериализуемого `IntermediateStoryBlueprint`, проверки событийных переходов, прав, тайных знаний, альтернативных выборов и `BookWorld` validator `gameplay_coverage=0` и `can_publish_bookworld=false`.

## Обязательные тесты M2b4a

- Локальный режим не совершает сеть и безопасно обрабатывает отсутствующую модель.
- Cloud opt-in: без разрешения **ни одной отправки**, отмена не оставляет незаявленной передачи и не меняет ранее подтверждённые цитаты.
- Prompt injection из FB2/TXT не способен выполнить инструкции модели, отправить данные или поставить `CONFIRMED` и `canPublishBookworld=true`.
- Fake provider выдаёт ложный span, чужой fingerprint, отсутствующее событие, 0-length evidence, surrogate split, duplicate id, oversized JSON и неизвестную категорию — все ошибки останавливаются до review/игры.
- Сохранение и возобновление после прерывания, замены модели, повреждения checkpoint, запроса удаления только semantic checkpoint.
- 10+ коротких оригинальных контрольных историй с цитатами, слухами, отрицаниями, одинаковыми именами разных лиц, алиасами, флешбэком, тайной до события, ненадёжным рассказчиком.
- CI по *точному* HEAD: Flutter analyze+widgets, Dart/Python/world checks, Android debug APK, Windows portable; ручные E2E Android/Windows, accessibility и долгие книги остаются отдельными явными QA gates.

## Запреты

Не добавлять второй домашний экран или импорт, не переводить существующие TXT/FB2 в `.bworld` автоматически, не удалять и не мигрировать старые сейвы, не делать сетевых запросов без явного согласия, не заявлять «AI анализ книги готов» до живой проверки. M2b4a — **инфраструктура для дальнейшего смыслового анализа**; далее M2b4b source-cited semantic extraction и M2c validated blueprint → только затем компиляция playable `.bworld`.
