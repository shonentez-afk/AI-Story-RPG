# AI Story RPG — сквозной аудит UX/UI до M2 (M1.7.4c3)

Дата: 2026-11-02. Базовый исходный код: `main` `0ff8e0f815b3929b73c1fb6cc0619dd536eee67c` (M1.7.4c3). Рабочая ветка: `audit/ux-ui-final-m174-20261102`; PR #4. Аудит относится к **существующему** Flutter-приложению Android/Windows: пилотной RPG M1.6, библиотеке TXT/FB2, подготовленным BookWorld и .bwsave v1/v2. Это не аудит ещё не созданного M2 Book Compiler.

## Методология и границы доказательств

1. Инвентаризация всех `apps/story_reader/lib` UI-экранов и 19 Flutter test suites, сверка с `UI_UX_AUDIT_2026-11-02_RU.md`, `READER_AND_GAME_UX_RU.md` и новым BookWorld-контрактом.
2. Анализ маршрутов, состояний загрузки/ошибок, возврата, дублей CTA и библиотек, файловой системы, восстановления и удаления, зависших задач, подтверждений и повторных нажатий.
3. Widget-регрессии на 320dp, 200% text scale, поиск мира, интегрированный v1/v2 импорт, неповреждение SQLite после отмены, F11/Escape, контрастность, предупреждения о неверном `.bworld`, 35+ сценарных решений.
4. Проверка цветов `ReadingPreferences` по WCAG `(Lmax+0.05)/(Lmin+0.05)`: светлая **16.29:1**, сепия **10.60:1**, тёмная **13.11:1**, OLED **21:1**. Это подтверждение **основного текста**, но не всех иконок/отключённых состояний и не сертификация WCAG в целом.
5. GitHub Actions должен пройти Python, Dart, BookWorld + SQLite, Flutter analyze + widget tests, Android debug APK, Windows portable. Конкретный последний SHA, run и PASS ниже добавить **после** проверки, не выдавая старый CI за актуальный.

**Границы:** интерфейс осмотрен по реализации и автоматическим проверкам. В этой среде нет запущенного физического Android, Windows GUI/монитора, аппаратного TalkBack/Narrator, пользовательских видеозаписей и инструментальной пиксельной QA. Не писать «визуальный и accessibility аудит на реальных устройствах PASS».

## Критерии перед началом M2

- **Код:** нет открытых P0 дефектов и актуальный PR CI 6/6 PASS; тесты не отключаются при ошибках, Android и Windows собираются на проверяемом SHA.
- **Навигация:** одна библиотека, одна CTA добавления книг, одни «Мои прохождения» и один глобальный импорт сохранений; изменение режимов не создает ход и не портит SQLite.
- **Данные:** не трогать `CampaignStore/SaveStore/GameProgress`, `.bwsave v1`, `.bwsave v2`, UUID/хеши миров, ZIP, исходные книги. Удаление BookWorld только после резервной копии; изношенный legacy слепок не «мигрировать» молча.
- **Малые экраны/доступность:** отсутствие RenderFlex overflow на 320dp/200% в проверяемых маршрутах; видимый возврат и отзывчивость кнопок; автоматический текстовый контраст >= 7:1.
- **Документация:** подписанная версия исходников, номер CI, PASS/FAIL/SKIP и контрольная инструкция `START_NEW_CHAT_RU.md` обновлены перед merge.

## Известные ограничения, которые нельзя назвать исправленными

1. **P1, обязательный аппаратный gate до публичного релиза:** Android/Windows настоящий системный FilePicker и внешние накопители (выдача пути не доказывает прочтение обратно), отключение питания, экспорт перед удалением, двусторонний перенос .bworld/.bwsave v2, возврат из фонового режима. Все эти сценарии подробно перечислены в `M174C3_PORTABILITY_RECOVERY_RU.md`. Их не подтверждает widget CI.
2. **P1, отдельная читательская архитектура:** сохранённая позиция в длинной книге пока использует пиксельный offset (старый M1.6 формат); при изменении ширины, шрифта или ориентации место может смещаться. Запланировать необязательный paragraph/source anchor с миграцией существующих bookmarks, не ломая старые сохранения. Это *не* дефект нового BookWorld и не основание переделывать весь главный экран.
3. **P2:** инструментальный TalkBack/Narrator, системный high contrast, реальное обходное управление Tab/Shift+Tab/Enter, видимый клавиатурный фокус и адаптивный иконка/splash на устройствах **не проверены**. Semantics/widget-тесты не эквивалентны настоящей accessibility-сертификации.
4. **P2:** исполнение 20 МБ TXT/FB2 в отдельном isolate не является измеренной производительностью на слабом телефоне; нужна реальная нагрузочная проверка и UI screenshot comparison.
5. **Функциональные, а не UI-дефекты:** TXT/FB2 пока не превращаются автоматически в готовую RPG, EPUB/Book Compiler, свободный AI/HYBRID режим не реализованы. Это M2/M3; в интерфейсе должны оставаться честные надписи.
6. Существующие M1.6 слоты допускают отдельное ручное удаление после предупреждения о необратимости; обязательный .bwsave v2 backup относится именно к новому BookWorld. Не делать вид, что у всех видов локальных сохранений одинаковые гарантии.

**Решение по аудиту:** после подтверждения актуального CI можно зафиксировать текущий UX/UI как *кодовый baseline* и не возвращаться к общему редизайну при M2. Это не пожизненная гарантия отсутствия багов: оставшиеся реальные device QA и будущие новые экраны требуют **точечных**, а не повторных общих аудитов.
