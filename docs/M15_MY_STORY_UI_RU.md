# M1.5 UI & Branding — утверждённая концепция «Моя история»

Дата: 2026-11-01. Статус: главное меню, связанное оформление библиотеки и настроек реализованы в Flutter. Иконка и системный splash ещё не заменены.

## Принцип
Один продукт, а не отдельные читалка и RPG. Цвета наследуются от AppTheme.light/dark; ReadingPreferences продолжает независимо управлять страницами книг и игровым текстом. Нельзя дублировать темы или менять форматы сохранений.

## Главная
- AppBar «Живая книга» и доступные по tooltip «Настройки» справа.
- Если есть игровое сохранение: заметная карточка «Сейчас в истории» → «Продолжить» с resume:true.
- Если нет сохранения: та же область → «Начать историю» и прямой запуск демо. Нет неактивной большой кнопки.
- Две адаптивные карточки: «Библиотека» и «Новая история». Экран до 360 dp переводит их в колонку.
- «Моя библиотека» показывает до восьми импортированных книг с обложками и переходом в конкретную книгу; при пустой библиотеке — явная подсказка.
- Не обещать «Недавно открытые»: текущий BookStorage не хранит timestamps посещений. «Моя библиотека» честнее.
- Не дублировать книги и не терять их id при переходе в читалку.

## Библиотека
Единый каталог: демо RPG, импорт FB2/TXT с обложкой. Значок книги с плюсом — добавить книгу. До появления связи «книга → RPG» нельзя выдавать импорт за создание игры.

## Настройки
Группы «Внешний вид», «Оформление страниц», «Режим игры», «Сохранения», «Версия». Не добавлять псевдопереключатели ИИ до реализации подключения провайдера.

## Брендинг — следующий технический шаг
- Мастер-мотив: раскрытая книга + тонкий символ портала/искры. Без мелких подписей.
- Базовые цвета: графит #1D1F23, светлый пергамент #F6F2E9, бронзовый #A58B70, тёплый #765B42.
- Android adaptive icon: безопасная центральная зона, foreground/background отдельно, монохромный вариант для Android 13+.
- Android 12+ system splash: фон и центральный символ. Не создавать дополнительный искусственный экран ожидания.
- Windows icon предусмотреть из того же мастер-знака.
- Сначала подготовить и проверить ассеты и сборочную интеграцию; **не менять** applicationId/package, сертификат подписи и путь данных. Текущий debug APK должен обновляться без удаления книг и прогресса.

## Регрессия
1. Пустая библиотека и отсутствие сохранений: запуск истории доступен.
2. Наличие игрового snapshot: «Продолжить» работает.
3. Импорт FB2 с обложкой: главная показывает книгу, открывает тот же bookId.
4. Светлая и тёмная тема: одинаковые карточки и контраст.
5. 320dp и textScale 2.0: карточки складываются вертикально без переполнений.
6. Маршруты Главная → Библиотека → книга → Назад и Главная → Настройки → Назад.
7. Сохранённые книги и RPG snapshots не мигрировать и не удалять.
8. Только зелёный Flutter analyze/test и успешный Android APK позволяют объявить пакет проверенным.

## Корректировка главной по пользовательскому UX-отзыву (2026-11-02)
Карточка «Библиотека» и блок «Моя библиотека» с кнопкой «Все книги» были **двумя входами в один каталог**, а не разными библиотеками. Это дублирование отменено: на Home один вход «Библиотека», без отдельной горизонтальной полки. При сохранённых книгах доступ идёт через LibraryPage (поиск, обложки, сортировка); функциональность чтения не удалена. Только в LibraryPage одна кнопка `Добавить книгу` независимо от количества книг; подсказки и appbar не дублируют импорт. На следующем этапe можно вернуть отдельный раздел «Продолжить чтение» только после реализации настоящего `lastOpened` и UX-тестов, а не по индексам первых восьми книг.
