# M2h8f1 — весь игровой план: ограниченные исходные запросы и продолжение без повторной оплаты

Дата: 2026-11-06. Статус: отдельная PR-ветка и тесты, НЕ включено в текущий основной выпуск.

## Зачем

Предыдущие PR #99–#104 проверяют предложение предметов/знаний только в рамках не более шести выбранных цитат. Для книги из десятков глав этого недостаточно. Новый контракт не обрезает сюжет первыми шестью событиями и не имитирует литературное понимание там, где ИИ не видел текста.

## Механизм

- Берёт **все события**, на которые действительно ссылаются решения полностью проиндексированного и структурно валидного StoryPlan, а не первые шесть по порядку.
- Группирует их в запросы существующего SourceLockedGameplayContext (максимум 6 дословных цитат, 16 выборов и 8 КБ в одном запросе). Если одна цитата даже сама по себе превышает ограничения либо связана с неопределённым решением, прерывается с ошибкой, не скрывает её.
- Допускает не более 32 запросов в плане, не более четырёх НОВЫХ запросов на одно отдельное явное подтверждение. Конкретный список всех сообщений и предел запросов доступны до согласия. SHA разрешения связан с редакцией, версией плана, точными отправляемыми байтами, моделью, лимитом запросов и максимумом повторов.
- При 429/обрыве существующий сервис повторяет те же байты максимум 3 раза. Не отправляет запросы при отключённом облачном ИИ, отсутствии API-ключа или неверном согласии.
- Сохраняет только краткие НЕПОДТВЕРЖДЁННЫЕ предложения с ID, названиями, привязкой к источнику, хешами и номером завершённого пакета — ни исходный текст книги, ни API-ключи, ни игровые сохранения в checkpoint не попадают.
- Сохраняет checkpoint атомарно в отдельной области Windows/Android после каждого завершённого пакета. При повторном открытии уже оплаченные/проверенные пакеты не отправляются повторно. Пустой ответ — полноценный зафиксированный результат, не повод выдумывать предмет или повторять запрос.
- Повреждённый checkpoint, смена редакции, плана, модели или бюджета запрещает отправку нового запроса до явного решения пользователя. Не считать записанный пакет завершённым, если запись на диск сорвалась.
- Показывает количество **неохваченных событий книги**, не притворяется, что StoryPlan уже охватывает все главы или что локальная цитата доказывает владение героя.
- Отдельно от этих предложений остаются PR #100 (проверка всех маршрутов), PR #102 (редакторский приём игровых выдуманных эффектов, запись в rich v3) и будущая независимая проверка литературного канона.

## Приёмка

Новые тесты используют оригинальную синтетическую многоактовую книгу, проверяют отсутствие сети до разрешения, количество новых запросов, resume без повтора, перенос пустых предложений, сохранение только source ID, несоответствие согласия после смены лимитов, отказ повреждённого checkpoint и ошибку записи без ложного прогресса. Никаких реальных облачных запросов в GitHub Actions.

**Не готово:** пользовательский экран с обзором всего плана/пакетов и настройками согласия, литературная оценка мотивации/знаний/владения, согласованная проверка дубликатов и конфликтов МЕЖДУ пакетами, перенос всего списка принятых эффектов в единый rich v3, режимы CANON/ALTER_FATE и устройство-ориентированный E2E. До этих этапов услуга «загрузил книгу — получил полноценную игру» не считается завершённой.
