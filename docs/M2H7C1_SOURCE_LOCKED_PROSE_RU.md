# M2h7c1 — source-locked художественный черновик одной сцены

**Статус:** подготовлен код и mock-тесты в отдельной ветке. Не считать принятым до точных CI/M0, слияния и post-merge проверки. Не выпускать как «полную RPG».

## Зачем

Нужны реальные описания ситуаций и диалоги, а не только технический текст StoryPlan. Первый инкремент безопасно предлагает художественный текст **одной** конкретной игровой ситуации через GLM 4.7 Flash. Он не изменяет сценарные правила, BookWorld, старые кампании или состояние мира.

## Реализованный контракт

1. Локально сверить BookSourceIndex, NarrativeBookModel, структурный StoryPlan, точный situation ID и исходную цитату по UTF-16. У предполагаемой исходной (canonicalProposal) сцены цитата обязательна.
2. До POST показать в интерфейсе context.consentPreview: цель, конфликт, точная цитата при наличии, допустимые действия и состояния. Отдельно предупредить о до трёх идентичных попытках при 429/5xx. Новый approvalDigest включает редакцию, хеш полного плана и показанный контекст. Старый digest после изменений не действует.
3. Только при явном userReviewedExactContext, совпавшем digest, разрешённом облаке и ключе в защищённом хранилище допускается запрос через существующий ZaiHttpTransport. Отправляется только контекст ОДНОЙ сцены, без названия и автора книги, fingerprint, файла, сохранений или секретов. Текст книги — недоверенные данные.
4. JSON результата содержит строго scene_id, prose, uncertainty. Лишнее поле, неверный ID, обрыв/незавершённый ответ, недопустимый размер или управляющие символы блокируются. ИИ не может присвоить статус CANON или новые действия.
5. Результат SourceLockedProseDraft: canInstallDirectly=false, canMutateCampaign=false, canPublish=false, hasVerifiedLiteraryMeaning=false. Не выдавать корректный текст за истинную причинность или подтверждённые знания NPC.

## Границы этого PR

Сервис и автоматические mock-тесты есть. **Нет** UI-кнопки для вызова, автоматической отправки, checkpoint результатов, художественного компилятора, реального GLM E2E и подтверждённого литературного качества. UI, локальная проверка смысла/флагов и применение только отдельно проверенной прозы в существующем BookWorld — следующий инкремент. Прямой POST в CI запрещён.

Основная цель пользователя — загрузить FB2/ZIP, выбрать режим, подготовить игру и играть, без редакторов. Проверяется по [Issue #83](https://github.com/shonentez-afk/AI-Story-RPG/issues/83).
