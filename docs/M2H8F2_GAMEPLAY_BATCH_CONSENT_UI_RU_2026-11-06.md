# M2h8f2 — экран пакетного сбора предложений GLM по игровому плану

Дата: 2026-11-06. Статус: отдельный PR поверх M2h8f1; проверка на Windows/Android обязательна до merge.

## Назначение

В существующем многоактовом мастере добавлена необязательная кнопка «Предложения по всему сюжету (пакетная обработка)». Она открывает экран чтения ТОЛЬКО исходных событий, к которым действительно привязаны игровые решения StoryPlan. Не охваченные сюжетом события учитываются и показываются отдельно, без заявления, что программа уже проанализировала каждый литературный факт книги.

## Последовательность для читателя

1. Открытие экрана ничего не отправляет и не создаёт кампанию. Показаны число пакетов, цитат, выборов, не охваченных событий и SHA согласия конкретной редакции.
2. По кнопке раскрытия видны точные русские цитаты и связанные решения, вложенный раскрывающийся блок содержит буквально JSON, который может уйти в Z.ai. API-ключ ни в один JSON не включается.
3. Нужно поставить ДВЕ отдельные галочки: проверка точного состава и разрешение ограниченного API-вызова. До этого кнопка запроса неактивна. Используется неизменный бюджет 2 новых пакета на отдельный запуск; при проблемах с соединением существующий сервис повторяет ТЕ ЖЕ байты максимум три раза.
4. Сервис M2h8f1 останавливается после бюджета, сохраняет только предложения и контрольные суммы в приватном checkpoint. При следующем открытии уже собранные пакеты и число кратких предложений восстанавливаются БЕЗ новой оплаты.
5. После каждого запуска обе галочки сбрасываются. Для следующей партии нужно новое сознательное действие. Закрытие страницы отменяет дальнейшие запросы, не меняет существующий мир или SQLite.
6. На экране честно сказано, что пока это НЕ игровая адаптация книги, НЕ литературный CANON и НЕ принятие в Hero / Items / Journal.

## Защита и приёмка

Модель продолжает получать только ограниченные фрагменты и ранее проверенные scene/choice/source ID. При повреждении checkpoint повторное использование запрещается. Одновременные вызовы по одной книге блокируются (M2h8f1). Widget-тест с синтетической многоактовой книгой проверяет ноль API-вызовов до галочек, однократный вызов после согласия, сброс разрешений, сохранение локальной записи и отсутствие повторной отправки после открытия экрана.

Этот PR **НЕ** объединяет результаты разных пакетов в игру. Модельные предложения ещё будут проверяться на единообразие ID и имен, владение, знания, причинность, совместимость по всем маршрутам, подтверждение человека и литературную трактовку. После этого отдельный rich v3 компилятор сможет применить согласованные игровые эффекты.

Реальных FB2 и личных ключей в публичных тестах нет. Никакой миграции несуществующих старых пользовательских миров.
