# План M1.2.1–M1.4: иллюстрации в чтении и RPG

Дата 2026-11-01.

## Реализовано в коде, пока без подтверждённого CI
- `book_model.dart`: `BookBlock` (`paragraph`, `heading`, `image`), `BookChapter`, `BookImage`, `SceneMediaBinding`, роли и spoiler policy.
- FB2 importer сохраняет последовательность текстовых блоков и изображений с `href="#id"`, декодирует ограниченные по размеру PNG/JPEG из `binary`.
- Сохранение JSON `schema:2` с ресурсами изображения; чтение существующих `schema:1` продолжает поддерживаться (legacy книги сохраняются).
- Читалка показывает иллюстрации между абзацами и позволяет открыть по нажатию в `InteractiveViewer`.

## Следующие этапы
### M1.2.2
- Проверить Android на реальных FB2 с внутренними JPG/PNG, вложенными секциями и иллюстрациями в абзацах.
- Исправить оглавления, стихотворные/вложенные элементы, image anchors, хранение больших книг без base64 JSON.
- Уточнить поддерживаемые кодировки XML и память при больших ресурсах.

### M1.3
- EPUB OPF/spine/XHTML, ресурсный manifest, cover, сохранение порядка текста и изображений.
- Ленивая загрузка, кеш миниатюр, безопасная проверка содержимого ZIP, ссылки только внутри архива.

### M1.4
- Слой `SceneMediaBinding` связывает `sceneId` с изображением книги, ролью, статусом открытия и запретом спойлеров.
- Игровой движок разрешает показ только после изменения подтверждённого состояния мира; импортёр сам не устанавливает истинность найденных улик.
- В интерфейсе: портреты, изображения локаций, карта, улики и инвентарь; клик «Осмотреть» только для реально обнаруженных объектов.
- Развилки могут использовать оригинальные ресурсы книги лишь если они не противоречат альтернативным событиям.

## Контроль качества
- Flutter analyze, widget tests и CircleCI Android build, затем тест APK на настоящем устройстве.
- Миграция schema 1 сохраняет старые книги и snapshot игрока.
- Не считать наличие модели `SceneMediaBinding` подтверждением, что она уже подключена к runtime: **игровое применение изображений ещё предстоит реализовать**.
