## Что сохранено и как ограничено удаление

Сохранены актуальные проверки main и открытых PR, выполняющиеся запуски, принятые CI #979/#975 и их M0, успешная внешняя baseline, нестандартные отчётные артефакты и родительские runs. Для известных типов артефактов активных веток защищены минимум две свежие успешные копии. Очистка не удаляет ветки, исходники, коммиты, PR, секреты или настройки; main не менялся.

DELETE ограничен одним репозиторием и разрешёнными endpoint: actions/runs, actions/artifacts, releases, только refs/tags/test-build-<число>. Перед каждым удалением run повторно сверяется status/run_attempt. Релиз проверяется по updated_at/immutable/tag. Тег удаляется только при неизменной ссылке и достижимом коммите. Для исторических orphan tags дополнительно проверяется точный известный SHA, отсутствие релиза и родство с main.

Полная пагинация и план составляются до удаления; ошибки API останавливают дальнейшую работу с частичным отчётом. Основной и завершающий проходы выполнены последовательно. Расписания нет, обычные изменения кода не запускают очистку. Текущий cleanup-request.json содержит только `verified_historical_test_tags`, а не повтор массового удаления. **Не запускать завершённую очистку повторно вслепую.**
