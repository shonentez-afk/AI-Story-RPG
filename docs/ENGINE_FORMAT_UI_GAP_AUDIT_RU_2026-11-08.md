# AI Story RPG — матрица разрывов между движком, форматом и интерфейсом

Дата: 8 ноября 2026. Ветка `feature/p0-bookwide-gameplay-readiness-20261107`, PR #133 Draft. Этот отчёт — **аудит, а не исправление кода**. По CI #987 / M0 #1072 успешно проверен код `6c3750ba`. В ветке после него были только изменения Markdown (сверено GitHub Compare).

**Метод:** инвентаризация дерева (171 Dart-файл приложения, 132 файла Flutter-тестов), углублённое чтение основных моделей `story_core`, `bookworld_format`, `campaign_manager`, редакторов, игрового GUI, Z.ai и связанных тестов. Проверялись четыре уровня: возможности ядра → допускаемые rich-v3 сценарии → `WorldGameView` → реальные Flutter-контролы. Это не построчная проверка всех 171 файлов, не ручной запуск Windows/Android, не живой GLM и не визуальные скриншоты; статус каждой проблемы ниже ограничен доказательствами.

## 5. Надёжность UI и доказательства

- GameQuickBar: четыре minWidth=72 плюс отступы требуют около 312dp; 280–300dp, text 200%, TalkBack/Narrator не приняты. [код](https://github.com/shonentez-afk/AI-Story-RPG/blob/6c3750bae27c30c5fdb67f17a055e6563e8081b0/apps/story_reader/lib/game_panels.dart#L96-L155)
- Независимые тёмная/светлая темы Flutter и палитра чтения: вложенные controls свободного ввода/диалога могут получить неподходящий контраст; нужен полный 3×4 контрастный widget/golden проход.
- Ошибки записи темы/чтения (`SharedPreferences`) сейчас не везде обрабатываются; удаление книги не предлагает удалить её приватные editor/checkpoint данные; эти дефекты уже зафиксированы в полном UX-аудите.
- `WorldBackupActions.saveWorld` принимает ненулевой путь от системного picker за доказательство существования файла; независимого физического чтения/переноса .bworld+.bwsave на Windows/Android пока нет. [код](https://github.com/shonentez-afk/AI-Story-RPG/blob/6c3750bae27c30c5fdb67f17a055e6563e8081b0/apps/story_reader/lib/world_backup_actions.dart#L14-L27)
- Старое demo `StoryReaderPage/GameProgress` и rich-v3 `WorldPlayPage/WorldGameView` имеют разный набор возможностей. Это граница совместимости, не повод создавать второй runtime.
- В репозитории нет сохранённых эталонных screenshots/golden PNG. CI подтверждает поведение и сборки, не физическую визуальную приёмку, живой GLM, background Android или доступность экранным диктором.
