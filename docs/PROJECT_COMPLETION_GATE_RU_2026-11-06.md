## Главная приёмка — полная книга

- [ ] Загрузка любой подходящей русской FB2 или TXT, точный индекс всех глав/событий/цитат, полный обход текста, контроль пропущенных фрагментов и восстановление после перезапуска.
- [ ] Список персонажей и alias с подтверждённой идентичностью, постоянными IDs, исходными знаниями и знаниями в каждый момент, предметами, мотивами, обязательствами, отношениями, присутствием и последствиями по всем ветвям. Источник цитаты не равен подтверждённому смыслу.
- [ ] Согласованный игровой сюжет **из всех существенных событий книги**, а не двух отрывков на акт. Проверка причинности, хронологии, времени, ветвления, достижимости концовок, знание NPC, владение и отсутствие временных парадоксов. Отчёт должен явно назвать оставшиеся пробелы, не делать ложных отметок полной готовности.
- [ ] Настоящий выбор подтверждённого героя/роли и доступного режима. **CANON** идёт по подтверждённой линии и не требует выдуманной второй концовки. **ALTER_FATE** предлагает игровые альтернативы с проверяемыми последствиями. Не отображать неподдерживаемые режимы как работающие.
- [ ] Один понятный мастер: добавил книгу → выбрал героя/режим → увидел объём анализа, расходы и приватность → разрешил GLM 4.7 Flash → проверил спорные выводы → получил `.bworld` и начал играть. Не добавлять вторую библиотеку/независимый движок/множество отдельных PR по полям.
- [ ] Путь должен не подменять полноценную игру укороченной пробной multi-act RPG. Текущий `StoryPlanTrialCompilation.isFullBookAdaptation == false` корректен; доводить новый авторский путь [по плану](P0_BOOKWIDE_AUTHOR_PATH_RU_2026-11-07.md).
