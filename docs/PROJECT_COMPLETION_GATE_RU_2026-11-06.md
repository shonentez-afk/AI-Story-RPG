## P0 — ещё не пройденная приёмка

- [ ] **Полный NPC:** события/память/отношения действительно изменяют choices/диалоги; владение вещами NPC и возвращение подтверждены event-chain, отсутствие/смерть/перемещения имеют реальные последствия; нет знаний из будущего, двойных личностей, предметов-призраков, обмана через SQLite/import. Тесты двух ветвей, сохранений и отрицательных случаев.
- [ ] **Путь автора:** книга → verified evidence → персонажи со стабильными ID → выбранный игрок → source-reviewed игровые эффекты/предметы → private rich v3 → запуск. `PrivateClassicScenarioTranslator` сейчас `items: []`, item transfer из обычного редактора ещё не получается, несмотря на готовность импортёра/движка.
- [ ] **Полная игра по книге:** все главы, StoryPlan, согласованные GLM акты, проверка литературы/мотиваций/знаний, цельная причинность, рабочие последствия и диалоги, честный отчёт об ограничениях.
- [ ] **CANON и ALTER_FATE:** только доступные герои и реально существующие развилки, не подменять оригинал необоснованным концом.
- [ ] **Один мастер / UX:** загрузка книги, выбор героя и режима, объём/стоимость, явное согласие, прогресс/возобновление, игра офлайн, без обязательного технического редактора и старых служебных кнопок.
- [ ] **Два реальных FB2+GLM:** включая тест «Король-лягушонок» с правами конкретного перевода, другая структурно отличная книга, полный Windows/Android E2E, отказ сети и восстановление сохранений. CI mocks не равны real E2E.
- [ ] **Релиз:** точный HEAD и post-merge CI/M0, Python/Dart/Flutter/SQLite/standalone CLI, engine dependency boundaries, сборки Windows/Android, SHA256, ручная QA на устройствах, release и задокументированные ограничения.
