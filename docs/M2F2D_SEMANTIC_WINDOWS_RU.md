## Исправление без потери оригинальных данных

**Новое** `SourceSemanticWindowPlanner.plan(index)` в `source_semantic_window.dart` группирует соседние исходные блоки **только одной главы** с жёсткими ограничениями: не более 12 `SourceChunk`, <=5000 UTF-16 символов и <=16 KiB исходного текста на окно. Заголовки FB2 входят как контекст, но не служат доказательством наличия персонажа/события. Отдельный заголовок без повествования нельзя отправить как окно анализа. Нельзя молча объединять части разных глав.

`SourceChunk.blockKind` сохраняется **только в памяти**; исходный индекс `toJson()`, fingerprint, координаты UTF-16, chunk IDs, оригинальная FB2/TXT и сохранения остаются совместимыми. Отправляемый документ для многоблочного окна содержит:

```json
{
  "book_title": "Свинопас",
  "source_chunks": [
    {"source_id": "c0_b0_p0", "kind": "heading", "text": "СВИНОПАС"},
    {"source_id": "c0_b1_p0", "kind": "paragraph", "text": "Жил-был бедный принц. ..."}
  ]
}
```

Названия, текст и весь состав окна **показаны до подтверждения**, checkbox по умолчанию выключен. В запросе нет автора, других глав, игровых сохранений, BookWorld, paths или source fingerprint; ни один сценарий не запускает отправку при просмотре страницы. Каждый следующий window требует нового согласия. Автоповторы M2f2b отправляют **тот же JSON** и применяются только в пределах уже данного согласия.

**Provenance:** модель должна вернуть `source_id` для каждой цитаты, если переданы `source_chunks`. Код проверяет принадлежность цитаты одному и только одному исходному chunk, затем точное положение, SHA, `SemanticCandidateValidator`, источник и Unicode-границы. Угадывать цитату по склеенному тексту запрещено. Для старых одиночных вызовов сохранён прежний контракт `untrusted_excerpt` с 4 полями ответа.

**Классификация:** prompt различает действия `event`, статические свойства `state` и явно выраженные намерения/отношения `fact`. Заголовки FB2 не становятся персонажами; общие существительные `королевство`, `сад`, `дворец` без собственных имён отвергаются в `location`. Узкий локальный предикат фильтрует конкретные статические описания, ошибочно классифицированные как `event`, не претендуя на общее лингвистическое понимание. Модель обязана писать объяснения по-русски, а цитаты сохраняются на языке оригинала. Все гипотезы остаются `INFERRED`; никогда не устанавливаются автоматически в канон.

В UI: «Окно N из M», полный видимый текст, подтверждение передачи исходных частей, русские названия категорий `Персонаж/Место/Событие/Состояние/Факт`, координата исходного фрагмента и список причин отброшенных предложений. Никаких записей в редакторы, BookWorld, SQLite, .bwsave, checkpoints.
