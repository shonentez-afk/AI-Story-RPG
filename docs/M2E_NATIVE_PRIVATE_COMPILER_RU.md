# M2e — встроенный Dart-компилятор приватных BookWorld для Windows и Android

Дата: 2026-11-03. Основа: main 73e57017, принятый PR #25, релиз test-build-297.

## Назначение

До M2e существовал только Python writer (tools/bookworld/private_bookworld.py). Android и Windows умели читать проверенный приватный BookWorld, но не самостоятельно собирать его из проверенных игровых правил. Это противоречит FR-IMP-12 (Android без Python). Мастер «Подготовить к RPG» пока не имеет законченного редактора M2c-сцен, поэтому результат индексации нельзя выдавать за готовую игру.

## Реализовано на этой ветке (ещё требуется CI)

- packages/bookworld_format/lib/private_bookworld_writer.dart — автономный компилятор Dart, без Python, сети, shell и LLM.
- Вход: предварительно проверенный сценарий ai_story_blueprint_v1 с private_adaptation, карта происхождения ai_story_private_provenance_v1 и оригинальный локальный индекс главы/фрагментов. UI ещё не предоставляет полноценный авторский сценарий автоматически.
- До упаковки проверяет SHA исходных chunks, fingerprint редакции, полное текстовое индексирование и каждую точную цитату по UTF-16 со спойлерными границами; подмена цитат и разрезание surrogate pair запрещены.
- Создаёт world.sqlite в одноразовом временном каталоге с проверяемой схемой и таблицами сцен/переходов; каталог очищается после операции.
- Упаковывает ровно 4 элемента ZIP_STORED формата v2; самопроверка производится отдельным PrivateBookworldImporter, который проверяет ZIP/SQLite/причинность.
- Добавлены негативные Dart-тесты. CI валидирует результат Dart-компиляции независимо через Python v2 verifier.
- Прежний original_demo v1, SQLite-кампании и файлы сохранений не мигрируются. Только private_use_only; публикация и отправка книги в сеть запрещены.

## Критерии приёмки

1. Exact PR HEAD: Dart analyze/test, независимый Python verify на созданном Dart архиве, Flutter analyze/test, Python/world, Windows и Android.
2. Merge только после полного PASS и M0. Затем отдельные main CI и Release с точным code SHA.
3. Ручной E2E на физических устройствах и стресс 20MiB/30k chunks остаются отдельными gates.

## Что ещё необходимо до ИИ

- Адаптер BookSourceIndex к writer через безопасный top-level isolate без захвата Flutter State; явные редакторские проверки и исходные checkpoints.
- Редактор персонажей, неоднозначных псевдонимов, сцен, действий, альтернатив и связей; отдельные save/resume/undo.
- Готовность по трём независимым шкалам: индексация, подтверждение фактов, исполняемый пакет. Кнопка «Начать игру» только после реального успешного импорта и доступной кампании CLASSIC.
- E2E на авторском рассказе, два финала, 20+ ходов, перенос сейвов Windows/Android.
- Только после этого: BYOK secure storage, opt-in на облако, лимиты запросов/расходов, provider gate, structured JSON и контроль prompt-injection.
