# M2: один локальный запуск подготовки книги и сохранение порций

Дата: 2026-11-02. Base: PR #21 `a8b016e3` и PR #22 `95c99fb7` прошли собственный CI и merged.
Этот этап — отдельная ветка `feature/m2-preparation-one-click-offline-20261102`, **до CI не принят**.

## Проблема после тестирования пользователем

«Подготовить к RPG» открывала сложный технический экран, где локальный
поиск повторялся отдельными кнопками и требовал ручного запуска каждых
24 фрагментов. После ревизии UX PR #20 стало понятно, как эти элементы
работают, но самой единой команды всё ещё не было.

## Реализуемый offline-first pipeline (без LLM)

Новая `OfflinePreparationCoordinator` с одной командой запуска:
1. Загрузить существующий M2b1 checkpoint и проверить exact source
   fingerprint, task IDs, UTF-16 offsets. Проверка/обработка имён порциями.
2. После каждого завершения порции atomically write checkpoint *до*
   обновления счётчика UI. Ошибка записи не допускает phantom progress.
3. Загрузить прежний независимый M2b3b narrative checkpoint; сохранить
   ранее проверенные упоминания (не превращать их в игровые факты).
   Обработать оставшиеся фрагменты, сохраняя каждую порцию.
4. Сформировать отдельный source-cited M2b4b catalog (только локальные
   шаблоны): предполагаемые события, состояния, имена, места, возможные
   псевдонимы и встречи; ИИ по-прежнему не подключён.
5. Все результаты доступны для независимой дальнейшей редакторской
   проверки. Отдельные M2c editorial и draft checkpoint не переписываются.
   Закрытие UI/«Остановить» ставит паузу между порциями, запуск возобновляет
   сохранённое. Повреждённый checkpoint нельзя молча удалять или перезаписывать.
6. Если исходные пользовательские решения уже существуют — сохранить их.
   Исходный текст не отправлять в сеть, сохранить старые кампании.
7. Подключить кнопку и статус к прежнему экрану `SourceIndexPreviewPage`,
   а не создавать вторую библиотеку или независимый импорт.

## Блокирующие ограничения

`canPublishBookworld=false`, `gameplayCoverage=0`. Реальный ИИ
по произвольной книге, проверенный canonical identity, сложная хронология,
знания NPC, создание сцен и M2d production `.bworld` ЕЩЁ НЕ ГОТОВЫ.
Не показывать «Можно играть» по завершении офлайн-поиска.

Дальше нужны production-компилятор M2d, право личной/публичной адаптации,
приватный контроль источника/сцены, редактор промежуточного сценария,
тесты на Windows/Android для короткого реального произведения. Только
после этого имеет смысл интегрировать model provider и UI настроек.

  остановка/продолжение с последнего checkpoint, ошибка записи,
  повреждённый исторический narrative/candidate не перезаписывается,
  ручные решения сохраняются, UI не обещает playable world.
- `source_semantic_catalog.dart`: новые source-cited имена, места,
  псевдонимы, возможные встречи; всё `INFERRED`.
- Полный CI exact SHA: Flutter analyze/test, Dart/Python/world contracts,
  Windows portable, Android APK. Ручной device E2E и нагрузка 20MiB/30k
  пока SKIP, нужен отдельный фактический прогон.
