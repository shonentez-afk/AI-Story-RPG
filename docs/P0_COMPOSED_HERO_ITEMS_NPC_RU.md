## Изменения

WholePlanGameplayBatchPage + ReviewedGameplayCompiler подключены к общему редактору героя и нескольких NPC. Предметы и факты одобряются для точного плана/архива: базовая игра героя → эффекты → NPC → строгий rich-v3 импорт → причинный аудит → SQLite. После изменения эффектов финальное NPC-согласие снимается.

Обнаружено ограничение: прежний rich-v3 импортёр отвергал сочетание gameplay_review и npc_knowledge. Новая проверка объединяет две независимо проверяемые области: ordinary review покрывает предметы/знания player; полный NPC-контракт покрывает только точный tuple scene/choice/actor/fact. Непроверенная цитата, чужой actor, неучтённый эффект или просто user_confirmed не дают разрешение. Схема и поля v3 сохранены, но совместное использование требует обновлённого импортёра.

Независимый Python reference tools/bookworld обновлён, не внешний E6d. Все прежние функции без изменения содержимого сохранены в private_rich_validation_core.py; public private_rich_bookworld.py использует их и проверяет объединённое покрытие. Никаких monkeypatch/eval/нового игрового движка. Новые Dart и Python отрицательные тесты включены. Dart создаёт настоящий ZIP/SQLite и передаёт эти же байты независимому Python-валидатору; Python не нужен installed game.

Диагностика отказа предметов теперь показывает статус аудита, число состояний, недоказанные действия/концовки и причины блокировки. Бюджет и требование исполнимости не ослаблены. Narrow-width UI-test нажимает собственно DropdownButton и прокручиваемую опцию, проверяет сохранённую роль, ревизию и заголовок. Прежние тесты сохранены.

## Ограничения

Мотивы/литературная причинность, CANON/ALTER_FATE, live GLM, две реальные разные RU FB2 и физический QA не выполнены. Эффекты пока живут в открытом редакторе; после перезапуска их повторно выбирают/одобряют по сохранённым предложениям. Реплики/роль сохраняются отдельно. Генератор реплик не получает автоматически runtime-истину о владении предметами. Приёмка должна ссылаться на точный новый кодовый SHA, а не старую зелёную сборку.
