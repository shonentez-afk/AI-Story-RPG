# M1.6.2–M1.6.3 — игровые панели и сюжет «Тайна особняка»

Дата: 2026-11-01. Рабочая ветка main.

## Реализовано
- Основной Dart story_engine остаётся единственным runtime для экрана игры.
- Семь сцен: gate, library, study, corridor, cellar, tower, secret.
- Старые идентификаторы gate/library и старые варианты enter/leave/finish сохранены для совместимости со snapshot из M1.
- Возможны несколько концовок (включая возвращение домой, прекращение расследования и два исхода раскрытия тайны). Не все концовки обязаны достигать последней сцены.
- Две реальные характеристики героя: Смелость и Наблюдательность.
- Предметы: Старое письмо, Латунный ключ и План особняка; они появляются только после соответствующих действий, не дублируются.
- Панели Герой/Предметы/Журнал показывают реальные текущие данные, журнал решений сохраняется вместе с engine snapshot.
- Новый прогресс хранится в старом ключе SharedPreferences, внутри версионированной оболочки, вместе с журналом. Прежний snapshot без оболочки продолжает считываться.

## Честные ограничения
- Это тематический детерминированный пилот, а не BookWorld или адаптация импортированной книги.
- Характеристики и предметы отражают решения, но пока **не блокируют и не открывают действия**: условия выбора следующая задача M1.6.
- Полноценный формат .bwsave, несколько слотов, автосохранение и Windows EXE остаются открыты.
- В старом snapshot нет информации для восстановления предметов: при загрузке старой записи характеристики по умолчанию нулевые. Игровой runtime снимок не меняется.
- Новый Flutter/Android CI должен завершиться успешно до передачи APK пользователю.

## Приёмочный сценарий для телефона
1. «Новая история» → «Войти и исследовать дом» → «Прочитать старое письмо».
2. Герой показывает Смелость 1, Наблюдательность 1; Предметы — «Старое письмо».
3. «Забрать план особняка» → «Открыть дверь в подвал»: характеристики меняются, инвентарь включает план.
4. «Сохранить», закрыть игру, на главной «Продолжить»: проверить те же характеристики, предметы и журнал.
5. Исследовать концовки, убедиться, что выбор «Начать заново» очищает характеристики, предметы и журнал.

## M1.6.4 — условия выборов и сохранность старых кампаний
- Для **новых** демо-прохождений действия зависят от реально найденных предметов: ключ открывает подвал, план — тайный ход и сохранение тайны, письмо — раскрытие правды; встреча с тенью требует хотя бы одну подсказку.
- Недоступный вариант виден, но его кнопка отключена, а причина написана под ним. Проверка повторяется при подтверждении действия, а не ограничивается одним UI.
- В старую оболочку сохранения добавлено **необязательное** поле `rulesVersion`: 0 для всех прежних прохождений (исходные выборы без ограничений), 1 для новых. Отсутствие поля распознаётся как 0. Старый ключ SharedPreferences и engine snapshot сохранены.
- Никаких искусственных предметов, внешних моделей и автоматической подмены действий не добавлено.
- Созданы unit и widget проверки различных концовок, недоступного подвала, чтения наследуемого сохранения и отказа от неизвестной версии.
- Требуется фактическое подтверждение нового commit GitHub Actions: Flutter analyze/test и APK. BookWorld и несколько кампаний остаются открыты.
