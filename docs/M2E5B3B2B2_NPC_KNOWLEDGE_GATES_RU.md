# M2e5b3b2b2 — явные условия знаний и разговоров NPC

**Дата:** 2026-11-03. **Основа:** M2e5b3b2a (`knows_fact` в проверке причинности) и M2e5b3b2b1 (длительные SQLite кампании).

**Статус:** CODE / EXACT-HEAD CI PENDING. Нельзя считать принятым без Python/Dart/BookWorld/schema/Flutter/Windows/Android/M0.

## Цель и результат

Автор сценария может вручную настроить проверяемое условие «этот выбор доступен, только если этот NPC (или игрок) уже знает конкретный факт», не добавляя текст тайны в BookWorld и не давая LLM право менять состояние мира.

- Расширена существующая страница **«Правила знаний NPC»**: после правил получения знания (`learn_fact`) есть отдельный визуальный конструктор условий его использования (`knows_fact`), с подтверждением, редактированием и удалением. Отдельных меню, библиотеки или второго игрового движка нет.
- `NpcKnowledgeGate` содержит только ID привязанного исходного правила, его SHA-256, ID выбора и SHA-256 выбора; валидируется оригинальная сцена, источник, глава, recipient и сам grant. Нельзя назначить условие на ту же выдающую выборку, на более раннюю главу или незаметно перенести его на другого персонажа. При изменении источника, SAME/DIFFERENT, заметки, получателя или сцены валидация блокируется.
- **Сохранения в прежнем формате v1 остаются байт-в-байт прежними** при отсутствии условий. Новый строго канонический `ai_story_npc_knowledge_rules_m2e5b3b2b2_v2` используется только при наличии gates; отдельный SQLite/.bwsave формат **не меняется**. Удаление выдачи с активным условием запрещено до удаления условия.
- `NpcKnowledgeWorldBridge` добавляет точное типизированное `knows_fact(actor, fact)` в ранее установленный `story_core`, только по явному opt-in в многосценном редакторе. Приватный `.bworld` проходит существующую независимую проверку `PrivateBookworldImporter` со state-space достижимостью, тупиками, 2 концовками и лимитом 2500 состояний. Никакой hidden fallback/AI.
- Визуально сообщается, что условие может сделать ветвь недоступной: автор исправляет сценарий, а не получает ложное подтверждение сборки. Отклонённый или повреждённый checkpoint не перезаписывается.
