# M2h8d7 — персональные офлайн-портреты говорящих (промежуточный этап)

Дата: 2026-11-06. Статус: PR поверх первого диалогового PR #115, до CI/слияния.

## Задача

Реальный портрет для известного говорящего **без ожидания несовместимого изменения .bworld**: человек вручную выбирает PNG на своём устройстве. Пользовательские изображения не отправляются в облако, не копируются в GitHub и не изменяют игровой сценарий.

## Реализовано

- Новый `LocalDialoguePortraitStore`, `apps/story_reader/lib/local_dialogue_portraits.dart`.
- PNG до 2 МиБ, ширина и высота 1–2048 пикселей, проверка подписи и IHDR, локальная SHA-256 адресация, повторная проверка bytes при чтении.
- Привязка изображения по SHA от пары `campaign_id + speaker_name`. Имя берётся **только из явной подписанной реплики**, а не вычисляется по догадке из текста. Портрет другого персонажа или другой кампании не подходит.
- При отсутствии, повреждении или удалении файла вместо картинки — силуэт, без произвольного URL, сетевой загрузки и ошибки игрового состояния.
- На `DialogueStage` добавлена кнопка «Выбрать портрет», только рядом с репликой известного говорящего. Смена говорящего меняет проверяемую привязку. На `WorldPlayPage` используется обычный локальный FilePicker; выбранные байты проходят валидацию, изображение сохраняется в Application Support, а UI обновляется без перезагрузки игры.
- Импортированный портрет **только косметика**: ни `story_core`, ни `SQLite`, ни `.bworld` не изменяются. Отмена выбора, испорченная или слишком большая картинка не стирают существующий портрет.
- Тесты: раздельные кампании и собеседники, неверные форматы, oversized, подмена локальных bytes, сохранность старого портрета после неудачной замены.

## Обязательные ограничения

Это не автоматическая генерация книжных персонажей и не доказательство их внешнего вида. Файлы пользователя не входят в переносимое `.bwsave`; на другом устройстве нужен отдельный выбор портрета. Локальные PNG-объекты с одинаковыми байтами могут разделяться; после удаления кампании физическую очистку неиспользуемых объектов следует проверить отдельно.

Первый этап принимает только PNG. WebP, изображения из FB2/EPUB, стилизованные эмоции, режим двух портретов и структурированные line/speaker_id/source-provenance — задачи **отдельного строго версионированного формата** по Issue #116. Не расширять неявно строгий `.bworld v3` и не подменять реальные данные полученными из интернета картинками.
