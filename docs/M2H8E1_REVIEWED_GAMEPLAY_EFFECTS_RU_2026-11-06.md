# M2h8e1 — принятые игровые предметы и знания в едином BookWorld v3

Дата: 2026-11-06. Состояние: отдельная ветка и PR на программной проверке, **не готовый автоматический GLM-режим**.

## Реализация

Принятые PR #96–#100 обеспечивают единый rich BookWorld v3, действующие вкладки героя/предметов/журнала, отдельные предложения ИИ, точные цитаты, явное разрешение на API и полный перебор игровых маршрутов.

Этот этап добавляет отдельное редакторское подтверждение:
- Читатель получает только уже проверенный source-index и rich v3 из подготовленной книги.
- Можно показать дословные события, соответствующие выборы, названия предметов/знаний и текст редакторского пояснения. Согласие применяется к ровно этой версии базы и предложений: SHA охватывает исходный архив, source payload digest и все пояснения. Изменение любого значения требует нового подтверждения.
- Литературный CANON не удостоверяется: читатель разрешает только вымышленный игровой эффект для частной адаптации. ИИ не получает право объявить владение или знание истинными. Никаких скрытых облачных запросов.
- Проверяются все ветки: нельзя расходовать несуществующий предмет, повторно выдать уже имеющийся или потерять предмет на неправильном пути. Можно выбрать подмножество предложений; противоречивые выбранные операции не применяются.
- Пакет пересобирается из неизменённого ранее проверенного rich v3. Получает новый bookworld_id, реальные typed grant_item/consume_item/learn_fact, локальные русские названия и отображение в Hero/Items/Journal. Существующие архивы и сохранения не меняются.
- Дополнительный необязательный source/provenance.json.gameplay_review хранит принятую пользователем декларацию, ссылки source_quote_sha256 на реальные источники оригинальных сцен, точные scene/choice/id и пояснение. НЕ является электронной подписью или независимой верификацией литературного смысла.
- Python и Dart v3 импортёры отвергают лишние/подложные эффекты, несовпадающие названия, ложные цитаты и ложное утверждение CANON. Старые rich v3 без этого поля продолжают открываться.
- GitHub Actions отдельно проверяет ровно тот ZIP, который собрал Dart, независимой Python-реализацией. Synthetic E2E покрывает получение/расход, разные исходы, SQLite-перезапуск и отказ при неверном разрешении.

## Важные незавершённые части

Текущий API редакторского подтверждения существует в сервисах и тестах, а не как законченный пользовательский мастер с сохранёнными локальными черновиками. Редактор сам по себе не доказывает авторскую причинность или владение NPC: для режима CANON это должно независимо проверяться на уровне книги.

До цели «загрузил FB2 и сразу играешь» нужны: автоматический многоактовый source-grounded GLM извлекатель предметов/знаний/событий, независимая литературная критика, выбор героя и CANON/ALTER_FATE, контрольные точки, UI подтверждения и реальные проверки двух разных книг на Windows и Android.

Запрещены публикация личных книг/ключей, скрытые платные запросы, выдача гипотез за канон и миграция несуществующих старых пользовательских миров.
