## Единый функциональный результат

В существующем общем редакторе соединены выбранный герой, проверенные предметы/игровые факты и несколько NPC. Старый source-bound GameplayBatchPage/Compiler не дублируется: базовая игра героя → отдельно одобренные эффекты → пакет NPC → строгий rich-v3 импорт → проверка всех прежних и новых исполнимых действий → SQLite-игра. Согласие связано с точным архивом/планом/ролью; смена эффектов отзывает итоговое NPC-согласие. Старые игры и исходные байты не изменяются.

Сквозная приёмка: Артем → ролевое наблюдение и воспоминание → получение ключа → SQLite закрывается с ключом → восстановление роли и inventory → расходование ключа → две другие NPC-встречи с независимыми знаниями/памятью → финал, hash-chain replay и переносимое сохранение. Ветка отказа не получает предмет. Невозможное расходование, другой герой, отозванная карточка, чужие байты и отсутствие согласия отклоняются.

Раньше rich-v3 импортёр запрещал одновременные gameplay_review и npc_knowledge. Теперь native Dart и независимый Python reference проверяют строгое объединение двух областей: предметы и факты player должны иметь ordinary review; знание NPC — отдельный проверенный tuple scene/choice/actor/fact с точной цитатой. Одно разрешение не покрывает эффект другой личности. Четыре новых Dart и пять Python тестов прошли. Настоящий Dart ZIP/SQLite дополнительно принят Python verify на тех же байтах. Installed runtime не требует Python, сети или ИИ.

Wire-схема v3 не менялась, но новые совместные миры требуют обновлённого импортёра; старый reader, запрещавший композицию, их не обязан принимать. Основной reference tools/bookworld изменён явно; внешний tools/rpg_author/E6d/pinned contracts — нет.

## Что осталось и что нельзя утверждать

Согласованный набор эффектов пока живёт только в открытом редакторе. После повторного входа нужно заново выбрать/одобрить эффекты по сохранённым предложениям прежнего batch-сервиса. Роль и реплики сохраняются отдельно. Модель диалогов не получает автоматически достоверное состояние владения предметом; смысл текста и мотивы требуют авторской проверки.
