## Что ещё не готово

1. Достоверная полноценная литературная RPG из произвольной загруженной FB2/ZIP; текущий работающий путь — лишь **частная пробная адаптация по двум цитатам**.
2. Автоматическое многоактовое планирование по всем значимым событиям, зависимости знаний/предметов/мотиваций, независимое подтверждение причинности и художественные диалоги.
3. Настоящие режимы CANON / ALTER_FATE, различная модель концовок и сильные последствия выборов на всей дистанции.
4. Реальный (не mock) контролируемый прогон GLM по одной публичной сказке «Король-лягушонок», прохождения на физических Android/Windows устройствах, литературная оценка.
5. Простой пользовательский путь загрузить книгу → выбрать режим → согласиться на анализ → начать **полную** игру; текущие страницы и пробный режим не следует рекламировать как этот конечный MVP.
