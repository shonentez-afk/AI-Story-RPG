## Активная разработка

- **[PR #76](https://github.com/shonentez-afk/AI-Story-RPG/pull/76)** — M2h2 первый многоактовый компоновщик StoryPlan из 2–6 независимых строго проверенных предложений по РАЗНЫМ частям книги. Все IDs/флаги/инварианты уникализируются по акту; переходы между актами сохраняют прежние решения и исходы, но явно обозначены **вымышленной игровой связью, НЕ доказанным каноном/хронологией**. Единый граф проверяет 2 финала, состояния, запрещённые обещания и покрытие источника. Тесты строят 3 акта и две разные сквозные цепочки. Ещё НЕТ вызовов GLM по актам, проверки литературного смысла или автоматического экспорта полного .bworld; статус только **DRAFT_ONLY**. Exact-head CI и Android/Windows обязательны перед merge.
- Следующим отдельным PR требуется независимая пользовательская/семантическая проверка переходов между актами и ограниченное получение нескольких актовых предложений от GLM при отдельном согласии на выбранные цитаты; затем проза сцен.

## Что не готово к цели

1. Полная литературная RPG по произвольной загруженной FB2 без ручного написания сцен.
2. Источник-обоснованные переходы между всеми актами, знания персонажей, предметы, длительные последствия каждого решения, CANON/ALTER_FATE на всём произведении.
3. Генерация сцен/диалогов и независимый контроль художественного качества, отсутствие хронологических и логических ошибок.
4. Реальный, не mock, GLM E2E для «Короля-лягушонка», две законченные линии с запуском и сохранением на Windows и Android, затем второй текст.
5. Простой режим «Загрузить книгу → Выбрать режим → Подготовить → Играть» как единый завершённый продукт.

Готовность CI подтверждает проверенную программу, НЕ правильность понимания романа. Не публиковать личные FB2/ключи в GitHub и не отправлять текст на Z.ai без отдельного согласия. Не менять уже установленные миры и SQLite-сохранения.
