## Границы реализации и следующие шаги

Всё ещё НЕТ полноценной литературной игры из произвольной FB2: нет независимого подтверждения смысла и причинных связей между актами, знаний/памяти NPC, предметов, нарастающих последствий, CANON/ALTER_FATE на всём произведении, художественных диалогов и полного экспортируемого .bworld. Шесть актов — временный технический предел одного черновика, не универсальная готовность.

1. Принять #77/#78 только при совпадении exact-head SHA и успешных CI: Flutter, Python/Dart, Android, Windows; затем проверить post-merge и релиз.
2. M2h5: источник-обоснованные причинные переходы между актами, независимые проверки семантики/хронологии/знаний персонажей, без выдумывания канонических событий.
3. M2h6: согласованные многосценные повествования и полноценные ветки CANON/ALTER_FATE; интеграция с проверенным приватным компилятором и SQLite.
4. Полный реальный E2E публичной сказки «Король-лягушонок» на настоящем GLM, Windows и Android, две концовки, сохранение; затем вторая книга без title-hardcode.
5. Упрощённый пользовательский путь «Загрузить книгу → режим → подготовить → играть», без обязательного JSON-редактора.

Никогда не считать зелёный CI доказательством литературного качества, не публиковать личные книги/API-ключи в GitHub, не отправлять цитаты без отдельного согласия, не перезаписывать старые сохранения.
