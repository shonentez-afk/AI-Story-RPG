## Новый код, приёмка ожидается

Общий процесс теперь содержит завершающую подготовку повествования для всех сцен и обеих развязок уже собранной кампании с героем, предметами и NPC. Предусмотрен явный путь оставить исходный текст без облачных запросов. Новый этап не устанавливает игру до полного согласованного результата; выход назад не устанавливает частичный вариант.

Контекст связан с точными байтами финальной игры и общим сюжетом; инвентарь вычисляется с учётом NPC-rulebook. В модель не отправляются подписанные скрытые реплики, секреты или сейвы. Единое показанное согласие охватывает только отсутствующие сцены. Сохраняются полученные пакеты и ручной текст; повторная подготовка не отправляет готовые сцены. Есть ограниченные повторы временных ошибок, отмена и сравнение точной версии сохранения.

Текстовой writer добавляет один русский абзац перед исходным телом каждой сцены. Цитаты, прежние пометки и разговоры сохраняются, поэтому это не окончательное удаление технических формулировок из игры. Прежние условия знания/памяти NPC переносятся с проверенным сдвигом позиции реплик, без смены говорящих или слов. Изменения всех механических полей запрещены, v3 writer/importer и полный StoryWorld causal audit остаются обязательными. Новая версия имеет новый bookworld_id и не перезаписывает сейвы.

Добавлены 11 новых тестов; их успешность ещё необходимо подтвердить на exact-head CI. Предыдущая зелёная база не выдаётся за проверку нового кода. Синтетический источник и тестовый API не заменяют живой GLM, две реальные RU FB2 или устройства.
