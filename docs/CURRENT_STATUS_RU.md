## Пользовательский результат

В одном существующем редакторе нескольких NPC теперь можно выбрать встречи, сохранить незавершённые ручные реплики, отдельно согласовать передачу точных цитат в Z.ai и получить предложения диалогов. Каждый готовый пакет сохраняется отдельно; после 429/обрыва можно продолжить с ещё пустых встреч. Сохранённые ручные, готовые и явно отказные результаты не отправляются автоматически повторно. Это не обещание отсутствия повторных расходов при потере ответа до сохранения.

ИИ не меняет постоянные character_id, источники, игровые зависимости и последствия. Автор проверяет/редактирует текст, затем отдельно одобряет всю кампанию. Сборка и прохождение используют прежние rich-v3/story_core/NpcSocialRulebook/SQLite. В installed game нет обязательной сети или модели.

Состояние редактора связано с SHA книги, плана и каталога NPC. Разрешения на облако/установку не восстанавливаются из checkpoint. Ошибка записи не создаёт ложного сохранения, конфликт ревизий не перезаписывает более новую ручную работу, повреждённый файл не заменяется молча. API-ключ и сырые HTTP-ответы не записываются в авторский checkpoint.

Сквозной новый тест: локальная фикстура с тремя NPC → первая модельная часть сохранена → 429 → новый экземпляр читает checkpoint → отправляются только две оставшиеся части → отдельное human review → настоящая private `.bworld` → production SQLite. Использован mock HTTP, а не живой GLM. Отдельно прошли отмена, model refusal, отсутствие согласия/ключа, подмена actor_id, ошибка записи и параллельные окна.
