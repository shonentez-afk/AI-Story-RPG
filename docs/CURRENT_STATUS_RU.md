## Активный этап

[PR #80](https://github.com/shonentez-afk/AI-Story-RPG/pull/80) — **M2h6: частная, реально играбельная МНОГОАКТОВАЯ пробная адаптация**. `MultiActTrialCompiler` использует только существующий M2c preflight → native private BookWorld worker → независимый ZIP inspector → SQLite runtime. Для 2–6 актов проверяет исходные цитаты и редакцию книги, требуются явные подтверждения всех цитат и статуса вымышленной частной адаптации. Новые страницы не меняют главное меню: из экрана анализа → подготовки актов → отдельная кнопка «Попробовать частную многоактовую RPG» → проверка цитат → создать новый частный мир и новую кампанию; можно отдельно подтвердить вымышленную связь, при которой поздний выбор закрывается после отказа в первом акте. Новая игра не затрагивает старые сохранения и играется офлайн. Тесты компилируют 14-сценный мир и проходят два разных SQLite-маршрута с рестартом на синтетическом произведении и общественном достоянии «Король-лягушонок». Первоначальный CI #578 выявил НЕТOЧНОСТЬ ТЕСТА: заблокированное действие остаётся видимым с lockReason; тест ожидал его отсутствия. Исправлено, функциональная проверка #580 прошла; после синхронизации с main нужен НОВЫЙ exact-head full CI (Python/Dart/Flutter/Android/Windows) и M0. Не сливать до его успеха, после слияния проверить post-merge release.

## Честные ограничения

- PR #80 даёт частную МНОГОАКТОВУЮ ПРОБНУЮ игру, но **НЕ** полную художественно точную RPG из произвольной FB2/ZIP. Пока автоматически подбираются только 2–6 актов и события не превращаются в полностью достоверный литературный канон.
- Не готовы независимая литературная причинность, мир-хронология (флешбеки), личности/знания NPC, проверка предметов/обещаний на всём произведении, художественные сцены/диалоги, режимы полного CANON/ALTER_FATE и качество концовок.
- Ещё требуется настоящий, не mock, GLM E2E по всей публичной сказке, Android/Windows device QA и вторая книга без hardcode названия.
- Следующая задача **M2h7**: источник-специфичная семантическая/литературная оценка сюжетных мостов и персонажей, затем генерация связанных художественных сцен, включая полноценные оригинальную и альтернативную линии; после реального E2E упростить путь «Загрузить → Режим → Играть».
- Не отправлять личные книги или ключи в GitHub, не посылать цитаты без явного согласия, не переписывать сохранения, не принимать зелёный CI за доказательство качества литературы.
