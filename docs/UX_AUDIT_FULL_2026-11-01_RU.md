# «Живая книга»: полный UX-аудит текущей мобильной версии

Дата: 2026-11-01. Основа: исходники Flutter в main, устройство пользователя (сообщение «работает»), CI GitHub Actions. Это **кодовый UX-аудит**, не лабораторное тестирование на десятках телефонов. Необследованные сценарии перечислены отдельно.

## Области проверки
Главное меню, переключение тем, библиотека и импорт FB2/TXT, обложки и иллюстрации, читалка, RPG, настройки чтения, панели, полноэкранный режим, прогресс, закладки, мелкие экраны, системная доступность, производительность и обратная совместимость.

## Исправлено в текущем пакете
1. **P1: позиция внутри главы**. Добавлено сохранение offset прокрутки по ID книги и номеру главы, совместимое с прежними bookmark records. Не обещать стабильность при изменении размера шрифта: pixel-offset смещается; следующий вариант — якорь абзаца.
2. **P2: лишний повтор заголовка/автора**. Показываются только на первой главе.
3. **P2: конфликт полноэкранных касаний с выделением текста/иллюстрациями**. В читалке удалён ненужный обработчик временного показа панелей. В RPG нижняя панель по касанию свободной области сохраняется.
4. **P2: плавающая кнопка на конце главы**. Добавлен дополнительный нижний отступ для кнопок листания.

## Подтверждено по коду
- Общие ReadingPreferences/ReadingSettingsSheet для книги и RPG, четыре палитры; AppTheme отдельно управляет оболочкой.
- Одна ReaderChromeButton для обоих режимов, normal/reading/fullscreen; в RPG gameplay choices доступны всегда.
- Книги и игровые snapshots сохранены в разных хранилищах; данные FB2 и медиа хранятся локально.
- Импорт TXT/FB2 UTF-8, FB2 встроенные PNG/JPEG; библиотека с карточками.
- Иконка импорта book-plus и компактная панель с 48dp зонами.

## Открытые пункты и ограничения (не выдавать за исправленные)
| Приоритет | Вопрос | Следующее решение |
|---|---|---|
| P1 | Большая глава: все виджеты FB2-блоков создаются сразу | Ленивая отрисовка и тест с длинной книгой, без потери прокрутки |
| P1 | Позиция — пиксельный offset; при смене размера текста или ширины экрана смещается | Модель прогресса по абзацу / проценту главы + миграция |
| P1 | У EPUB нет импорта и оглавление FB2 пока нумерованное | EPUB и структурированные заголовки главы |
| P2 | SettingsSheet пока без демонстрационного образца текста | Живой превью внутри настроек |
| P2 | Крупное системное масштабирование и TalkBack не проверялись | Android-матрица шрифтов 1.0/1.5/2.0 + семантический аудит |
| P2 | Разница между полным экраном и чтением у книги небольшая | Позже добавить полезные контекстные book-controls или упростить три режима |
| P2 | Слишком много текста у кнопок сохранения/некоторые заголовки могут переполнить маленький экран | Widget tests на 320dp, large textScale; overflow QA |
| P2 | Автосохранение RPG после выбора не реализовано; один слот | M1.5 persistent world state, slots and checkpoints |

| P3 | Главный экран показывает одну демо RPG без реальной обложки | Следующая редакция библиотеки |
| P3 | Планшет/Windows адаптация в основном ограничением maxWidth | Проверить пользовательские сценарии и клавиатуру |
| P3 | Панели Герой/Предметы/Журнал пока информационные | Подключить реальные игровые модели |

## Обязательная регрессия перед переходом M1.5
- Выбрать тему на главной, читать FB2, открыть RPG, проверить цвета и настройки в обоих режимах.
- Длинная глава: прокрутить, закрыть, открыть, проверить сохранение главы и приблизительной позиции.
- Перейти к другой главе, проверить прокрутку с начала, закладки и прежний формат storage.
- В читалке: выделить текст, открыть иллюстрацию, увеличить, не показать верхнюю панель случайным тапом.
- В игре: режим reading/fullscreen, тап по пустой области вызывает только нижние инструменты; сюжетные решения нажимаются.
- Проверить управление на 320dp и при увеличении шрифта 2x.
- Подтвердить успешный GitHub Actions flutter analyze/test и debug APK (не считать успехом до завершения run).

## Исполнение исправлений по запросу пользователя — 2026-11-01

**Внесено в исходники:**
- Ленивая отрисовка длинных глав FB2/TXT через `CustomScrollView + SliverList.builder`; текст, иллюстрации, навигация и книга загружаются внутри той же главы. Добавлен тест главы на 300 блоков.
- Из FB2 `<section><title>` теперь формируются заголовки, оглавление отображает названия глав. Добавлены тесты импорта и перехода по оглавлению.
- Общий `ReadingSettingsSheet` для книги и RPG содержит живой образец текста с выбранными цветами, шрифтом и интервалом.
- Проверка малого экрана 320dp с системным увеличением текста 200%; кнопки листания адаптированы через Wrap. Размер общей кнопки управления увеличен с малого FAB до 56dp; в RPG добавлен нижний запас, чтобы не закрывать сюжетные действия.
- Сохранение положения внутри главы и регрессионный тест повторного открытия длинной главы; старая запись progress поддерживается.
- Старая коллекция GitHub Releases удалена отдельной задачей Actions; сохранён последний доступный на момент очистки тестовый выпуск; новые успешные сборки удаляют предшествующие Android-тестовые релизы.

**Не заявлять завершённым до следующего этапа:**
- При изменении размера шрифта точность позиции пока зависит от offset, семантический якорь абзаца не реализован.
- Полная TalkBack/VoiceOver-проверка на реальном устройстве, исследование поведения больших файлов с большим количеством фото, Windows/планшет и TTS ещё не выполнены.
- EPUB, полнотекстовый поиск и настоящий игровой инвентарь — расширение возможностей, не часть текущего UX hotfix.
- Новый Android APK считается подтверждённым только после зелёного GitHub Actions.
