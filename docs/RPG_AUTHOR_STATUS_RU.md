# Внешний генератор: продолжение разработки

Дата: 5 ноября 2026 года. Ветка: `feature/external-rpg-author-e1-20261105`.
Основа: `e18924cd9cb8c65bd948d370c28d32c3ee429ab4`.

## Граница задачи

Пользователь поручил начать внешний генератор и **не вмешиваться в основное
приложение**. Изменения только добавляют `tools/rpg_author/`,
`tests/rpg_author/`, `schemas/rpg_author/`, документы генератора и отдельный CI.
Не менять `apps/`, `packages/`, существующий компилятор и планы параллельной
разработки приложения. Не объединять ветку с `main` автоматически.

## Сделано

Версия 0.1.0: TXT/FB2 → индекс → задания ассистенту → проверенные по цитатам
предложения → структурный сценарий → полный ограниченный обход состояний →
JSON-кандидат. Есть SHA-привязка книги и инструментов, атомарный manifest,
неизменяемые контрольные точки, продолжение, замена с инвалидированием сценария,
запрет рабочих данных внутри checkout и сохранение ИИ-авторства.

Инструкции и команды: [EXTERNAL_AUTHORING_RU.md](EXTERNAL_AUTHORING_RU.md).

## Проверки

- Локально: **46 тестов генератора**, включая командный процесс в отдельных
  интерпретаторах, UTF-16, кодировки, подмены цитат, условия, тупики, циклы,
  прерывание записи, повторную подачу и сохранение происхождения данных.
- Локально: **21 существующий тест компилятора BookWorld**, без его изменений.
- Добавлен независимый CI `External RPG author tests`: Python и Dart parity.
  Перед продолжением проверить его актуальный HEAD и результат по GitHub.
- Dart-зонд сравнивает 20 случаев индексации с настоящим приложением и
  передаёт кандидат сцен настоящему `StoryBlueprint`. Локального Dart SDK
  в этой рабочей среде нет; нельзя объявлять проверку выполненной локально.
- Нет пользовательского E2E по книге, проверки устройства и оценки литературы.

## Существенная незавершённая совместимость

Существующий приватный импортёр допускает только
`model_provenance={provider:none, model_id:null}`. Внешнее ИИ-авторство
не должно исчезать ради успешного импорта. `build` намеренно возвращает
`external_ai_provenance_unsupported` и не создаёт `.bworld`.

Это не исправлять обходом проверки или правкой приложения в этой ветке.
Для будущего выпуска пакетов требуется отдельное решение о версии и семантике
метаданных происхождения. Работа над моделью/сценарием генератора может идти дальше.
