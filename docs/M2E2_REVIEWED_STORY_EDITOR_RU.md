# M2e2 — редактор короткой частной RPG без ИИ

Дата: 2026-11-03. Зависимость: M2e native writer принят PR #26, code 47a9d89e. Новый код M2e2 в отдельной ветке, до собственного CI НЕ принят.

## Реализованное поведение

В существующей Библиотеке одна кнопка «Подготовить к RPG» и одна страница подготовки. Внутри появляется переход «Редактор личной адаптации», а не новая библиотека.

Редактор:
- Загружает из приватных scoped checkpoints уже обработанные цитаты и смысловой каталог. Отказывает при неполном/чужом источнике, устаревшей редакции или некорректной контрольной сумме.
- По умолчанию скрывает события, предотвращая спойлеры. Пользователь должен отдельно раскрыть список.
- Предлагает выбрать два исходных события, для которых точные цитаты уже отдельно подтверждены. После этого пользователь вручную подтверждает каждое событие как редакторскую основу сцены. Слова/имена/другие INFERRED записи не повышаются автоматически.
- Пользователь вводит текст вступления, канонического и альтернативного финалов, тексты двух действий. Привязка к исходной книге остаётся у двух исходных сцен; альтернатива помечена явно как пользовательская.
- Черновик M2c хранится в отдельном приватном checkpoint intermediateDraft, редакторские решения — в semanticEditorial, исходник и ранее созданные сохранения не меняются. Перезагрузка восстанавливает поля.
- Только при явном согласии на ЛИЧНОЕ использование вызывает ReviewedStoryComposer → PrivateClassicScenarioTranslator → native Dart writer через top-level worker. Потом архив проверяется и атомарно устанавливается через существующий WorldLibraryGateway, открывается обычный экран кампаний. Никакого Python, HTTP или LLM.
- Если нет цитат, пользователь видит причину, а не фиктивную зелёную кнопку «Готово».

Это лишь **тестовая короткая адаптация выбранных событий**, не автоматическая компиляция всего романа, не создание свободных персонажей и не подтверждение публикационных прав.

## Границы и тесты

- Новые unit tests: наличие явных canonCandidate + confirmed source, исправленная хронология, два исходных утверждения и собственный альтернативный финал; отрицательные пустые редакторские решения.
- Новые widget tests: ошибка при отсутствии подготовленного каталога, спойлеры скрыты до действия, согласие требуется перед компиляцией.
- **CODE / CI PENDING**: до exact PR SHA Flutter analyze/widget + Dart/Python/world, Windows+Android + M0 не merge. Ручной Windows/Android E2E и длинные книги остаются SKIP. См. START_NEW_CHAT_RU.md и docs/STATUS_RU.md.

## Дальше перед реальным подключением ИИ

- Полный редактор идентичностей/псевдонимов, причинной хронологии и сцен для большой книги; пакетные решения, Undo, история изменений.
- Три независимые шкалы готовности: текстовый охват, проверенные смысловые факты, реально исполняемый пакет; отчёт без ложных «100% RPG готово».
- Авторский story E2E с 20+ ходами, Windows/Android физические устройства, откат после сбоев, производительность на большой книге.
- Лишь затем BYOK/secure storage, consent на отправку фрагментов, cost/token budgets, модельная верификация, prompt injection защиты.
