# M2h8e3 — выбор предметов и знаний в многоактовой пробной RPG

Статус: 2026-11-06, отдельная ветка, PR и точный CI обязательны. Это продолжение UI PR #103 и компилятора PR #102, которые не могут объявляться принятыми до окончательной проверки.

## Что добавлено

На странице «Пробная игра по частям книги» появилась отдельная НЕОБЯЗАТЕЛЬНАЯ кнопка для предметов и знаний.

- После того как читатель сверил все исходные цитаты и разрешил частную адаптацию, он может перейти к исходно-ограниченному Z.ai предпросмотру. Открытие страницы ничего не отправляет. Перед API-вызовом нужно отдельное согласие на показанные конкретные фрагменты.
- Один запрос ограничен шестью дословными событиями выбранной редакции и шестнадцатью соответствующими игровыми выборами: это НЕ автоматический анализ всей книги. Остальные главы не выдаются за проверенные.
- Можно оставить игру без предметов либо выбрать отдельные предложения и написать собственное пояснение, что это частная игровая выдумка, а не канон.
- При создании базовой многоактовой RPG запускаются уже принятые M2c/StoryPlan/BookWorld source-проверки. После этого выбранные предложения проходят полный перебор достижимых веток из PR #100. Только после второго явного подтверждения создаётся НОВЫЙ rich .bworld v3 с реальными grant_item/consume_item/learn_fact.
- Дополнительное вымышленное правило исхода первого акта и отдельное редактирование предметов взаимоисключаются, потому что правило меняет игровой граф. Не допускается использование проверки для старого варианта плана.
- SQLite-сохранения и ранее созданные игровые миры остаются прежними. Без дополнительных предложений все существующие варианты игры работают как раньше.
- Новые widget-тесты: отдельное разрешение на запрос и явное отсутствие автоматического вызова без него, запрет смешивать несовместимые изменения сценария, возврат к подготовке без игровой мутации.

## Оставшиеся этапы

Пока это необязательная обработка отдельных дословных цитат. До цели «загрузил FB2 → выбрал режим → играешь» нужны встроенная автоматическая многопроходная обработка всего произведения, литературная проверка мотивов/хронологии/знаний NPC, выбор героя и режим CANON/ALTER_FATE, устойчивые checkpoints и полноценный прогон на двух разных книгах с настоящим GLM на Windows/Android.

Никаких платных скрытых вызовов, приватных файлов или ключей в публичных тестах. Не создавать миграцию старых пользовательских кампаний, которых в проекте не было.
