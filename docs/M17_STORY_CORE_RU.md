# M1.7.1 — детерминированное ядро мира и JSON-контракт подготовленных сцен

**Базовый коммит (до этапа):** `17d99e1a339e401d795f7db19e14613cad786753`, GitHub Actions `41334189482` — SUCCESS, включая Android и Windows.

## Что сделано в исходниках

- `packages/story_core` — **новый чистый Dart-пакет**, без Flutter, файлового доступа runtime, Python, ИИ и сети. Никаких изменений текущей `StoryReaderPage`, кнопок, SharedPreferences и пилотного `.bwsave`.
- `StoryBlueprint.fromJson` проверяет версию, согласованность ссылок между сценами, терминальные сцены, каталоги предметов/фактов, ID акторов, дубликаты, доступность веток и ровно объявленные режимы; выражения задаются только разрешёнными типизированными `conditions/effects`, никакого `eval`/динамического кода.
- `StoryWorld.apply` проверяет выбор против **текущей сцены**, выполняет предикаты до эффектов, готовит обновлённое состояние во временных копиях и публикует его только после успешной проверки **всех эффектов**. Ошибка во втором эффекте не создаёт предмет из первого.
- Идемпотентность подтверждённого `action_id`, `expectedRevision` для отказа от устаревшего действия, immutable `WorldState`, отдельные наборы известных фактов игрока/каждого NPC, ограниченные характеристики/время, детерминированные SHA-256 состояния и цепочки событий.
- `StoryWorld.replay` пересчитывает мир из исходной схемы и полного журнала, сверяет каждый hash, последовательность и реальные эффекты. Изменённый event или пропущенный шаг вызывает отказ, а не тихое доверие подменённому состоянию.
- `shared_schemas/v1/story_blueprint.schema.json` — реальная **JSON Schema Draft 2020-12** промежуточного blueprint; `shared_schemas/fixtures/manor_world_m17.json` — **наша оригинальная тестовая история**, 8 сцен и 15 определённых вариантов выбора. В фикстуре явные `rights_status=original_demo`, `source_fingerprint=null`, только режим `PROTAGONIST/CANON/CLASSIC`. Нет ложной связи с импортированной чужой книгой.
- Отдельный job GitHub Actions `story-core` блокирует публикацию APK/Windows при FAIL, выполняет `dart analyze`, `dart test` и Python `jsonschema==4.23.0` проверки. Dart тестовый маршрут включает **35 подтверждённых действий**, повторный независимый прогон и точное восстановление по event log, идемпотентность, условия, повреждение и недостижимые переходы. Отрицательные проверки схемы включают неподдерживаемые режимы и исполняемые payload.

## Архитектурная граница — не путать с готовой игрой

1. `story_engine:0.1.0-alpha.1` остаётся **основным сценарным runtime (ADR-001)**; `story_core` не заменяет его и не копирует алгоритмы его внутреннего навигатора. Этап M1.7.1 — подготовленный **контракт и модель авторитетного состояния мира**, не второй runtime в старой кампании.
2. Blueprint JSON — **не готовый ZIP `.bworld`**. В частности, нет `world.sqlite`, криптографического архива ресурсов, полной provenance/coverage, действительных `source_refs`, автоматического компилятора книги. Схема ограничена original-demo сценами и явно не поддерживает AI/HYBRID.
3. **Пока нет интеграции нового ядра в игровые экраны** и сохранения пользователя; существующий M1.6 `GameProgress` остаётся фактическим состоянием пилота. Перенос значений без миграции запрещён.
4. `StoryWorld.apply` атомарен **только в памяти**; не является ACID/SQLite. Целевая атомарность UI+story_engine+world_state+event log должна обеспечиваться `StoryRuntimeAdapter` + SQLite/Drift в M1.7.2–M1.7.4, вместе с миграцией, резервными копиями и тестами прерывания питания.
5. SHA-256 защищает от **случайного повреждения и обнаруживает изменённый replay**, но не удостоверяет подлинность (нет MAC/подписи; злоумышленник может пересчитать журнал). Межплатформенная детерминированность проверяется контрактно в Dart CI, не фактическим Android+Windows E2E-синхронным прогоном.

## Защита от версии другого мира (M1.7.1 hardening)
- `StoryBlueprint.blueprintHash` = SHA-256 канонического JSON **всего** проверенного blueprint, а не только `book_id`; `WorldEvent.blueprint_sha256` включён в payload цепочки и проверяется на каждом шаге replay. Сохранение с другой редакцией мира не принимается молча.
- `StoryWorld.replay(..., expectedSequence, expectedStateHash)` позволяет обнаружить обрезанный **конец** журнала, если ожидаемый head сохранён в доверенном checkpoint. Без ожидаемого head корректный префикс принципиально неотличим от прежней точки сохранения, поэтому обещать обнаружение любого удаления хвоста нельзя.
- Прототип отвергает неподготовленные роли/сюжетные режимы: только `PROTAGONIST / CANON / CLASSIC`, синхронно и в JSON Schema, и в Dart validator. Реальных ROLE/PLOT мастеров и генерации ИИ ещё нет.
