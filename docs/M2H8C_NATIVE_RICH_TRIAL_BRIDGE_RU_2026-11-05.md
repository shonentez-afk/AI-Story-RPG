## Реализация M2h8c — отдельная ветка

1. `RichPrivateBookworldWriter.upgradeReviewedV2` строго принимает только ранее проверенный локальный private-v2, заново сверяет ВСЁ цитирование по тому же `BookSourceIndex`, создает отдельный rich v3 с устойчивым новым `bookworld_id`, переписывает SQLite и независимо открывает готовый пакет rich-импортёром.
2. Инвентарь, характеристики и знания **не создаются искусственно**. Если в исходном v2 есть каталоги, требующие отдельной семантики, перенос запрещается вместо выдумывания имён и эффектов.
3. Выбранная подпись героя поддерживается явно (`heroName`), нейтральный временный вариант — «Игрок». Заголовки игровых сцен можно автоматически брать из проверенного StoryPlan; слишком длинные/опасные заменяются нейтральной меткой. Это **не** доказательство литературного CANON.
4. Если исходный v2 не может удостоверить автора модели, записывается `provider=unknown, model_id=null, model_id_status=not_attested, method=reviewed_local_compilation`, одинаково строго в Python и Dart. Нельзя приписывать настоящей генерации `provider=none`; `zai` и `openai` остаются отдельными честными атрибуциями.
5. `compileReviewedRichPrivateBookworldInWorker` повторно применяет уже принятые M2c/preflight/проверку цитат, затем в отдельном Flutter isolate собирает rich v3. Не вызывает интернет и не расходует API-запросы.
6. Короткий и 2–6-актовый сценарные компиляторы переводятся на единый формат v3 без изменения игровой логики. Текущие UI-страницы по-прежнему требуют явного подтверждения частной игры и установки, а `WorldLibraryGateway` устанавливает rich пакет и создаёт новую SQLite-кампанию.
7. Тесты должны доказать: два раздельных исхода, replay/SQLite restart, отсутствие подложных предметов, отказ при неверной редакции или чужой сцене, неизменный результат флаговых выборов; Dart -> Python проверяет **те же байты** архива после перехода v2->v3. Часть проверок запускается только после создания PR.

## Что ещё НЕ реализовано

- Полный автоматический GLM-перевод semantic catalog/StoryPlan в **семантически подтверждённые** `grant_item`, `consume_item`, `stat_delta`, `learn_fact` с реальными цитатами из конкретной книги. Пока реальные флаги/решения и журнал; пустые каталоги — корректное отсутствие данных, а не готовая полнота.
- Процедура выбора реального персонажа и режима CANON/ALTER_FATE на простом главном экране; сейчас «Игрок» — честная нейтральная временная подпись.
- Самостоятельная межактовая литературная GLM-проверка двух реальных веток с новым, раздельным согласием. PR #93 готовит точный пакет входных данных и находится на отдельной проверке.
- Сквозной живой GLM-прогон «Короля-лягушонка» и другой книги на Android/Windows, контроль литературной целостности и публичный релиз полного MVP.
