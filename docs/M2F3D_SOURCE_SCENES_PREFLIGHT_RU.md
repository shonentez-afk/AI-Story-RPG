# M2f3d — исходные сцены, контекст утверждений и отчёт готовности

Дата: 2026-11-04. Базовая ветка `main` на старте: `5c10e042b69f0711aa1f6b5988f2a008f8335763`. Исторический main CI `41768473194` SUCCESS + M0 `41768473214` SUCCESS. Последний тестовый релиз `test-build-427`, содержащий M2f3c. Рабочая ветка `feature/m2f3d-source-scene-preflight-20261104`.

## Реализация

- `zai_source_scene_board.dart` — независимый, **строго редакторский** `ZaiSourceSceneBoard`. Из `ZaiCrossWindowEvidenceGraph` используются только **оставленные пользователем на проверку** цитаты `SemanticCategory.event`. Сцену можно вручную создать из 1–8 событий **одной главы**, дать название и пояснение, удалить или поменять порядок карточек. Дублирующееся использование события, ссылки на другой тип цитаты, чужую редакцию и перемешивание глав отвергаются. Порядок карточек — редакторская компоновка, **не хронология мира книги**. Никаких альтернативных выборов, NPC-фактов или игровой механики не создаётся.
- Отдельный `ZaiClaimContextNote` для выбранных `fact`/`state`: `narratorText`, `characterSpeech`, `disputed`, `unknown`. Это классификация **формы и источника утверждения**, а не его истинности. `isVerifiedWorldTruth=false` при любой отметке. Утверждение без keepForReview и событие другого типа не принимаются.
- Приватный checkpoint в `SourceCheckpointScope.zaiSceneDraft`, папка `ai_story_zai_private_source_scene_draft_m2f3d_v1`: только fingerprint текущей редакции, уникальные IDs исходных цитат, названия и заметки, статус `PRIVATE_DRAFT_NOT_RPG`, SHA-256 и `can_publish_bookworld=false`. Не сохраняет полный текст/цитаты, имя автора, API-токены, пароли и историю кампании. Лимиты 192 сцены, 8 событий/сцена, 800 контекстов, 512 KiB. На восстановлении ID проверяются заново против актуального keepForReview. Любая подмена, изменение редакции, отзыв решения или частичный файл блокирует загрузку. Нет миграции/перезаписи M2f3a–c.
- `ZaiSourceSceneWorkbenchPage` — новый экран из `ZaiCrossWindowReviewPage` по кнопке **«Черновые сцены и отчёт готовности RPG»**. В пределах выбранной главы показывает точные цитаты и номера окон, позволяет вручную выбрать до восьми событий, требует отдельного выключенного по умолчанию подтверждения при создании сцены, изменять порядок, комментировать источник утверждений, открыть исходное окно и удалить свои черновые сцены.
- **Спойлерный барьер:** при первом открытии M2f3d показывает события **только первой главы**, будущие не раскрывает. Для любых остальных требуется нажатие «Разрешить показ будущих глав» и подтверждение «Показать будущие главы». Согласие действует только до закрытия экрана; не сохраняется и не передаётся ИИ. Эта функция НЕ меняет отдельные спойлерные ограничения существующего BookWorld/NPC.
- Новый `ZaiScenePreflight` — воспроизводимый **блокирующий** отчёт: есть ли сцены, незаконченные окна/редакторские решения, покрытие оставленных событий, факты без контекста, нерешённые вопросы M2f3c, возможные конфликты формулировок, расхождение порядка сцен с ручными временными гипотезами; отдельно объясняет, что отсутствуют проверенные игровые выборы, причинные изменения состояния и настоящий связанный компилятор. `canStartPlayableRpg=false` и `canPublishBookworld=false` **всегда**, даже при полном покрытии.
- Нет сетевых запросов. **Никаких автоматических канонических фактов, RPG-сейвов, .bworld/.bwsave/SQLite, фонового ИИ, авторских прав на книгу или правок файлов библиотек**. Существующий M2c `IntermediateStoryBlueprint` не подменяется «обработанными» цитатами без отдельного семантического preflight.

## QA
