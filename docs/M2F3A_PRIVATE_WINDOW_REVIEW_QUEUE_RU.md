# M2f3a — приватная очередь смысловых окон Z.ai

Дата: 2026-11-03. База: main `f99b458a02a935c8f2fbbf7c82f0418d8f11a3f3`. Рабочая ветка: `feature/m2f3a-private-window-review-queue-20261103`.

## Что реализовано

- Новый `ZaiWindowReviewQueue` в `zai_semantic_review_queue.dart`: строго упорядоченный список окон M2f2d, прогресс завершённых окон, номера непроверенных, список исходных цитат и ручные отметки «Оставить на проверку» / «Отклонить».
- Повторный анализ одного окна заменяет его гипотезы и сбрасывает старые ручные отметки только этого окна. Другие окна и книги не переписываются.
- Отдельный `SourceCheckpointScope.zaiWindowReview` использует тот же атомарный файловый механизм, но независим от старых `semanticProposals`, каталога, редактора, TXT/FB2, `BookWorld`, SQLite/.bwsave и API-ключа.
- Checkpoint хранит fingerprint редакции, позиции и точные ID окон, кандидатские цитаты/координаты/SHA, версии провайдера, контрольную сумму и решения. При чтении все кандидаты заново проходят проверку по исходному тексту. Максимум 10 MiB.
- Страница Z.ai восстанавливает очередь при входе и отображает результаты прошлого окна, прогресс и кнопку «Следующее непроверенное окно». Никаких фоновых запросов и автоматического продолжения отправок; каждый запуск сетевого запроса требует **нового согласия на точный текст этого окна**. Старые лимиты 3 попытки на согласие/Retry-After/429 и отмена действуют.
- Выбор «Оставить на проверку» — **не утверждение факта, не принятие канона**, а приватная редакторская гипотеза. `canPublishBookworld=false` всегда.
- В checkpoint **не хранятся** автор, исходная книга целиком, HTTP-запросы, ключи, история RPG или ответы без источника. Точные короткие цитаты сохраняются для локальной проверки. Вредоносные/чужие/устаревшие данные не должны заменять последний корректный checkpoint.

## Что остаётся M2f3

1. Ограниченная по частоте обработка нескольких отдельно подтверждённых окон, безопасная пауза/возобновление, наглядные расходы и ошибки.
2. Дедупликация персонажей и алиасов без ошибочных слияний, структурирование отношений, событий, причинных зависимостей и хронологии, разрешение конфликтов с подтверждёнными цитатами.
3. Человеческий редактор с явным каноническим подтверждением, созданием промежуточного графа и строгим preflight до BookWorld.
4. Физический Android/Windows E2E и проверка большого FB2. **Не включать свободную игровую LLM до отдельного M2f4.**
