# M2e5b2 — авторские карточки NPC с проверяемыми источниками

**Дата:** 2026-11-03. **База:** `main` `76f10718c7f3ff18d5fdfd86d555aac20f6fbdbd`; M2e5b1 принят: PR #31, CI `41564955358` и M0 `41564955391` SUCCESS. Для M2e5b2 до exact-head CI использовать статус **CODE / QA PENDING**.

## Пользовательский путь

Одна библиотека → книга → «Подготовка книги» → «Персонажи, события и хронология» → раскрыть спойлеры → **«Авторский редактор NPC»**.

После ручной проверки исходных упоминаний можно создать **локальную авторскую карточку** одного существующего source-досье. В ней доступно отображаемое имя адаптации и любое число (в рамках лимитов) типизированных записей:

- **роль** персонажа;
- **мотивация / цель**;
- **знание**;
- **секрет**;
- **отношение** к другому подтверждённому source-досье.

Каждая запись по умолчанию явно авторская. Дополнительно можно привязать её к существующему `SourceSemanticAssertion`, которому редактор ранее присвоил `CANON_CANDIDATE`, и к его exact-span цитатам. Даже связанная с цитатой запись **остаётся гипотезой / авторским комментарием**; она не превращает цитату в доказанную мотивацию или в игровой канон.

Ссылки на существующие досье проверяются по **точному набору ID исходных упоминаний**. Если пользователь изменил SAME/DIFFERENT или отозвал цитату, ранее сохранённый NPC notebook **не открывается и не мигрирует незаметно**. Отдельная подтверждаемая команда может удалить *только* собственные заметки NPC при невозможности продолжения; исходные цитаты, разметка идентичности, книги, `BookWorld`, кампании SQLite, `.bwsave`, короткий и многосценный сценарий остаются.

## Технические ограничения и приватность

- Новые: `npc_editorial_notebook.dart`, `npc_editorial_page.dart`.
- Источники данных строго существующие: `BookSourceIndex`, `SourceEvidenceGraph`, `SourceSemanticCatalog`, `SemanticEditorialReviewSession`, `SourceRelationReviewSession`, `SourceCharacterDossierIndex`. Никакой второй canon-движок.
- Новая приватная папка `SourceCheckpointScope.npcEditorial`: `ai_story_npc_editorial_m2e5b2_v1`. Запись через существующую атомарную файловую реализацию, отдельную от всех предыдущих checkpoints.
- Формат `ai_story_npc_editorial_m2e5b2_v1`, SHA256 целостности (не цифровая подпись), exact fingerprint; строгие поля и roundtrip-проверка, лимиты 2 МБ/256 карточек/48 заметок/800 символов на заметку.
- Только подтверждённые `EvidenceKind.character` с разрешёнными chapter-gates могут стать опорой локального профиля. Source-linked утверждения требуют вручную принятого `canonCandidate` и всех подтверждённых chapter-visible цитат; совпадение написания имени **не подтверждает личность**.
- Сведения не передаются ни модели, ни серверу; никакого live ИИ, export, публикации или автоматического изменения `story_core`. `canPublishBookworld=false`, `isVerifiedWorldCanon=false`, `isLlmPromptApproved=false`.

## Тесты приёмки

`npc_editorial_notebook_test.dart`: роли, знания, секреты и source candidate; ссылки на другую группу; отзыв цитат/вердикта; изменение SAME; чужая редакция/порча checkpoint; недопустимые заметки; изоляция трёх прежних хранилищ и атомарность.

`npc_editorial_page_test.dart`: создание, сохранение, повторное открытие; ошибка записи не становится ложным успехом; смена решения SAME блокирует старую карточку, не стирая её; явная отмена/подтверждение сброса только NPC.

Принятие только по exact-head: Python, Dart, Flutter static+widget, BookWorld/schema, Windows portable и Android APK, M0. Физические испытания Windows/Android, книги большой длины, игровые NPC и долгие кампании остаются **SKIP**, не `PASS`.
