## Метод и статус

Проверяются текущие Flutter-маршруты и хранилища: главное меню, библиотека и одна CTA импорта, обычная книга TXT/FB2, восстановление чтения, настройки приложения/страниц, существующая подготовка и анализ, пилотная RPG, BookWorld и прохождения. Изучены предыдущие отчёты `docs/UI_UX_FINAL_AUDIT_M174C3_RU.md`, `M174C3_PORTABILITY_RECOVERY_RU.md`, дорожная карта и текущие widget/contract тесты. Внесены адресные исправления с регрессиями (ниже).

Аудит кода и автоматизированного UI **не является** пиксельным/аппаратным визуальным аудитом. НЕТ реального запуска APK/EXE на устройстве, скриншотных сравнений мониторов/телефонов, аппаратного TalkBack/Narrator, проверки power-loss и полной проверки текстового ввода FilePicker. До успешного CI точного HEAD никаких PASS не заявлять.

## Проверка полноты настроек

**Реально поддерживается:** отдельная тема приложения (светлая/тёмная/системная), палитра чтения свет/сепия/тёмная/OLED, размер шрифта 12–32, межстрочный интервал 1.2–2.2, поля 12–48, сброс оформления, одна библиотека и импорт TXT/FB2/.bworld, история прохождений и импорт/экспорт .bwsave, информация о демо/offline и версии. Настройки сохраняются в `SharedPreferences` и не должны переписывать чужие данные. **Не реализовано:** подключение реального локального/облачного AI и соответствующих параметров API, провайдеров/ключей, EPUB, аудио/голос, тонкие права при публикации — это новые функциональные этапы, нельзя показывать неработающие переключатели.

## Проверка открытия книги

1. Импорт TXT/FB2 через единую библиотеку — проверка расширения, размера, реального UTF-8/1251/16 и валидного XML. Новые данные атомарно сохраняются, старая библиотека читается параллельно без зависания кадра.
2. Карточка показывает прямую команду «Читать», отдельную подготовку книги, удаление с подтверждением. Отказ записи или повреждённая книга не удаляет пользовательские файлы.
3. BookReaderPage восстанавливает chapter, scrollOffset, semantic paragraph anchor и bookmarks до отображения текста. Ошибка чтения прогресса — явный retry, не подмена старой позиции нулевой. Смена шрифта, ориентации и режима чтения продолжает использовать принятый anchor.
4. Экран чтения TXT/FB2: оглавление, главы, изображения, полноэкранный режим, закладки, чтение без готовой RPG. M2b3c граф/сюжет — только редакторские гипотезы с source citations; `gameplayCoverage=0` и `canPublishBookworld=false`.

## QA и остающиеся ограничения

- Все добавленные/изменённые Flutter тесты должны пройти по **точному SHA** GitHub Actions (Flutter analyze, widget, Dart/Python, BookWorld SQLite contracts, Android APK, Windows portable). После FAIL исправить фактическую причину и повторить до 6/6 PASS.
- Реальный Android FilePicker, Windows FilePicker, перенос .bworld/.bwsave, OS screen reader, клавиатура, physical 320dp/200%, power loss, производительность романа 20 MiB/30k chunks — **SKIP/не подтверждено**. Не называем эти проверки успешно пройденными без оборудования и фактических измерений.
- В автоматическом определении Windows-1251 для старого TXT без декларации есть эвристика. Для экзотических KOI8-R/CP866 сейчас выдаётся ошибка, не обещается универсальное распознавание.
- Крупная библиотека пока загружает все сохранённые книги в память в рабочем isolate; UI не блокируется парсингом, но энергопотребление и память слабого телефона требуют отдельной проверки. Для промышленного масштаба — индекс метаданных и ленивое чтение выбранной книги.
- Вложенные редакторы M2b остаются логически разделены по источникам и spoiler gate. Прямой доступ к подготовке уже виден в библиотеке, но отдельные редактируемые вкладки/сквозные search/pagination для больших книг всё ещё кандидаты M2b4.
