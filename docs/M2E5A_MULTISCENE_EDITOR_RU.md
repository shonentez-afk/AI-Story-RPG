# M2e5a — многосценный сценарный конструктор для личной RPG

**Дата:** 2026-11-03. **База:** main `5d5560e8cc7946fa65c8881fccc4ad7cf3441dab` — M2e4a принят (CI `41560992466`, M0 `41560992271`, all SUCCESS).

**Статус текущего этапа:** CODE / CI PENDING. Не объявлять релизом до exact-head CI, приёмки PR и следующего Windows/Android artifact.

## Архитектура и пользовательский путь

1. Библиотека книги → единственная страница **«Подготовка книги»** → **«Конструктор многосценной RPG»**. Вторая библиотека не создаётся.
2. Сначала редактор короткой адаптации M2e2 подтверждает две исходные сцены и авторский альтернативный финал. **Копировать** эту 3-сценную основу в новый независимый многосценный черновик (без автоматического повышения неподтверждённых цитат).
3. Добавлять источник можно только из подтверждённых `event/fact` со статусом `CANON_CANDIDATE`, существующим exact-span evidence и корректным chapter spoiler gate. В новой source-сцене текст по умолчанию — короткая исходная цитата, не ИИ-пересказ; автор может отредактировать отображаемый текст.
4. Можно добавлять авторскую альтернативу с пустым текстом и позднее заполнить её; вводить новые связи сцен, подписи выбора, условия `requires/forbids` и последствия `adds/removes` на флагах. Новые scene/choice IDs создаются безопасно, без исполнения произвольных скриптов.
5. Ручное удаление сцены блокируется, пока на неё ведут другие переходы. Начальную сцену удалить нельзя. Сохраняются в том числе **незавершённые** черновики.
6. Кнопка «Проверить сюжет и причинность» использует **существующие** `PrivateAdaptationPreflight.evaluate` и `IntermediateStoryBlueprint.validate`: проверка source fingerprint, цитат, прав, всех ссылок, достижимости **каждой** сцены, доступных действий в каждом состоянии, ≥2 различных концовок, цикла без выхода, условия и изменения флагов.
7. Кнопка «Собрать и открыть личную RPG» требует точного проверенного неизменённого черновика, отдельного согласия `privateUse`, сохранения черновика, **тех же** `compileReviewedPrivateBookworldInWorker` и `WorldLibraryGateway.install`. Структура ZIP/SQLite проверяется до пользовательской игры. Нельзя считать готовность равной полному охвату романа.

## Сохранение и совместимость

- Новый enum `SourceCheckpointScope.multiSceneDraft` и изолированная папка `ai_story_multiscene_draft_m2e5a_v1`.
- Старые `intermediateDraft`, книги TXT/FB2, `semanticEditorial`, source evidence, `BookWorld`, SQLite, кампании и переносимые `.bwsave` не изменяются.
- Незавершённые черновики проходят отдельную безопасную проверку размеров/структуры/fingerprint при чтении и записи, но **не** считаются игровыми пакетами. Повреждённый checkpoint не заменяется незаметно пустым.
- Нет внешних API, LLM, публикации/экспорта полного текста или автоматического определения канона. `privateUse` не подтверждает право публично распространять книгу.
