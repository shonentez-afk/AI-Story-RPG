# M2d — preflight частной адаптации до реализации настоящего .bworld

Дата 2026-11-02. Контракт независим от LLM, пока **не создаёт** ZIP, SQLite,
не меняет original-demo формат и старые кампании.

## Для чего

Модель не должна иметь права самостоятельно переписать первоисточник или
объявить догадку игровым каноном. Нельзя путать точную цитату,
ручную отметку «подходит для адаптации», право на распространение и
готовность игрового графа. Это четыре независимые проверки.

## Новый контракт

`PrivateAdaptationPreflight.evaluate(index,evidence,catalog,editorial,draft)`:
- требует одинаковый exact fingerprint и source-backed citations;
- запускает M2c bounded causal simulation, два доступных окончания, отсутствие
  тупиков и спойлеров из будущих глав;
- исходные сцены обязаны ссылаться на утверждения, отмеченные редактором
  `canonCandidate`; `passageOnly`, `rejected`, `disputed` блокируют;
- источник должен быть отмечен `EvidenceStatus.confirmed`, причём это
  подтверждает только наличие цитаты, не её объективную истинность;
- альтернативные сцены явным образом `explicitAdaptation`, а не притворяются
  оригинальным сюжетом;
- `rights=unknown` блокирует; `privateUse` **не разрешает** публикацию;
  даже `publicDomain` пока лишь декларация без независимой проверки прав;
- не принимает редакторский checkpoint чужой версии каталога;
- возвращает структурные показатели, список точных unmet gates и
  `canCompilePlayableBookworld=false` до настоящего M2d сборщика/импортёра.

### Обязательная следующая реализация

1. Схема `book-derived` ZIP/SQLite с source fingerprint, provenance,
   model provenance, rights, сохранёнными вручную проверенными решениями,
   отдельная от старого `original_demo`. Собственный compiler/validator;
   ни одна строка в старом M1.7 runtime не должна просто стать permissive.
2. Полная Dart/Python parity: несанкционированные ZIP entries, подмена хешей,
   чужой исходник, спойлеры, права, неизвестные операции, все reject.
3. Транслятор M2c `IntermediateStoryBlueprint` в исполняемые
   `StoryBlueprint` rules и офлайн-классический runtime, 20+ ходов,
   реальный короткий **авторский** рассказ с двумя исходами.
4. Приватное сохранение результата в существующей библиотеке, отдельные
   кампании, checkpoint/recovery, перенос Windows↔Android, без миграции старых.
5. Затем — consent+BYOK/локальная модель и реальные semantic proposals,
   benchmark 10+ контрольных историй, ограничение токенов/стоимости, отказ
   от спойлеров и network fallback.

## Расширенная pre-AI приёмка (уточнение после аудита)

**Не путать три независимых результата:** (A) полностью проиндексирован исходный текст, (B) смысловые утверждения и сцены вручную/машинно проверены на достаточность, (C) получен валидированный пакет .bworld, запускающийся в CLASSIC. A не гарантирует B; B не гарантирует C.

### Незакрытые обязательные задачи, строго в порядке зависимостей

1. **Стабилизация объединённого мастера** — один запуск, последовательные mentions→evidence→catalog, resume после отмены/сбоев, без повторного индексирования; явная стадия REVIEW REQUIRED и справка по уровню доказательности; no-source-data warning.
2. **Семантическая полнота** — независимые entity ID/alias, мотивы, действия и результаты, отрицание/условные и чужие реплики, временные отношения, ложные рассказы, знания/секреты NPC; только подтверждаемые точными цитатами утверждения могут войти в игровой канон. Нынешний regex не обеспечивает этого автоматически.
3. **Редактор источника и сценария** — массовые решения, объединение/разделение одинаковых имён, проверка хронологии/противоречий, сцены/действия/варианты и явное разделение оригинала/авторского дополнения. Сохранять отдельно от исходной книги, включая undo и fingerprint invalidation.
4. **M2d production v2** — отдельный book-derived writer + strict Dart/Python reader/validator с совместимостью legacy original_demo; rights/provenance/spoiler/security limits, zero implicit permission to publish. Пайплайн из verified IntermediateStoryBlueprint → deterministic StoryBlueprint → ZIP + SQLite, привязка source fingerprint к private BookWorld.
5. **End-to-end game acceptance** — на небольшом оригинальном рассказе: >=2 достижимых финала и альтернативное действие, >=20 ходов, разные состояния после изменения причины, отсутствие softlocks и утечек будущих глав, перенос и восстановление Windows↔Android без сети, не трогая старые сейвы.
6. **Release/security** — signed/checksum package validation, corrupt ZIP/traversal/zip bomb/foreign source/invalid SQL reject; accessibility и большая книга отдельно; отчёт по coverage с реальными отказами; исправления по реальным E2E.

### Критерии перед реальным подключением ИИ

- M2d checker различает `privatePlayable`, `shareable` и `notReady` в проверяемой, а не самодекларируемой форме.
- Список неподтверждённых событий и глав конечен и видим игроку; отсутствует ложная зелёная «100% RPG готова» при частичной обработке.
- Реальный источник, authored non-AI сценарий и negative fixtures проходят одну и ту же проверку Dart/Python и runtime.
- Провайдер не вправе писать directly в BookWorld/сохранения и не должен иметь сетевого fallback. Только после этого подключать model API с BYOK+consent+budgets.

### Текущее ограничение этапа

Этот PR реализует **только предварительный защитный preflight**, не M2d writer/importer/runtime. Его положительный результат не означает `canCompilePlayableBookworld=true`, а юридическое обозначение `publicDomain` само по себе не является доказательством прав. До отдельного end-to-end acceptance готовая игра по чужой книге не заявляется.
