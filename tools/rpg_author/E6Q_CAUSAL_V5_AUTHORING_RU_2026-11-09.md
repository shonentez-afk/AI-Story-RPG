# E6q: сценарная причинность для CANON v5 из всей книги

9 ноября 2026. Версия внешнего генератора `0.3.0a20`. Согласование с нативным контрактом `ai_story_source_causal_review_v2` в Draft PR #133.

Команда:

```
python -m tools.rpg_author author-causal-v5 --project PRIVATE_PROJECT --base-world PRIVATE_V5_LITERAL.bworld --workdir PRIVATE_REVIEW --output PRIVATE_REVIEW/causal_review.json --user-confirmed
```

Оригинальная `PRIVATE_V5_LITERAL.bworld` должна быть собрана и проверена **штатным нативным v5-компилятором**, а не генератором. Генератор читает реальные UTF-16 исходные цитаты и ZIP-манифест, требует полный реестр сцен, подтверждённые исходные имена NPC, реальные ссылки на события, объяснение причинности каждого события и внешнюю литературную проверку. Сценовые задания разбиваются по **8 сценам**. Все ответы создаёт сам приватный ChatGPT Skill через `PrivateResponseInbox`; API Z.ai или другая модель не требуется. Строго отклоняются подложные цитаты, задним числом появившиеся NPC, дубли, будущие зависимости, неподтверждённые эффекты, пропуски и unresolved. Изменения только в папке генератора.

Выход `causal_review.json` содержит `event_graph` для КАЖДОЙ сцены, `witnesses`, `invariants`, `npc_reactions`, `source_fingerprint`, SHA базового архива, явное разрешение пользователя. Этот **JSON ещё не игра**: его должен повторно проверить и превратить в новый BookWorld штатный `compile_reviewed_causal_canon` из `rpg_api`. Отсутствие `--user-confirmed` или непроверенная причина не создаёт финальный файл.

**Оговорки:** корпус в CI искусственный; реальная литературная правдивость и мотивы не следуют из SHA и не доказываются автоматически. Отдельный навык/пользователь должен авторски проверить все сцены; по умолчанию `semantic_canon_automatically_verified:false`. Контракт на актёров зависит от текстового первого упоминания имён и требует явного source witness. Бюджет 512 КБ на одну входную задачу; слишком длинный каст не обрезается, нужен source-window review. Старые E6p сохранения привязаны к точному toolchain и автоматически не мигрируют.
