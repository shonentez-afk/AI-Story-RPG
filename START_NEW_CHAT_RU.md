## Реализованный единый пользовательский поток

Подробности: [P0_RESUMABLE_AI_NPC_AUTHORING_RU.md](docs/P0_RESUMABLE_AI_NPC_AUTHORING_RU.md). Актуальная сводка: [CURRENT_STATUS_RU.md](docs/CURRENT_STATUS_RU.md).

Подтверждённые цитаты/карточки NPC → выбор разговоров → отдельный просмотр точных отправляемых данных и числа запросов → ИИ предлагает русские реплики → каждый полученный пакет сохраняется → автор редактирует/одобряет → прежний компилятор создаёт автономную игру. В installed runtime сетевых зависимостей не добавлено.

NpcWritingStore сохраняет выбранные встречи, незавершённые/готовые ручные реплики, модельные предложения/отказы и зависимости под отдельным приватным корнем через существующий atomic checkpoint repository. SHA книги, плана и карточек проверяются при восстановлении. Ключи, сырые HTTP ответы и разрешения на облако/установку не сохраняются. Исходные цитаты отдельно не дублируются, но написанные реплики могут содержать слова книги. Повреждённый/устаревший файл не перезаписывается молча; удаление требует явного подтверждения. Ревизии защищают от обычной конкуренции окон в одном процессе. Принудительное отключение питания до записи отдельно не испытывалось.

ZaiNpcCampaignWriting использует прежние AiCloudPreferences, AiApiKeyVault, ZaiModel и AiHttpTransport. Отправляются только выбранные пустые встречи с двумя точными цитатами, actor/candidate IDs и уже заданными условиями. Модель не меняет личности, зависимости, сцены или игровые эффекты. Ответ считается непроверенным текстом либо явным отказом, не каноном.

429/временные обрывы повторяются ограниченно, с теми же байтами; квота/ключ/неправильный JSON не вызывают слепых повторов. Отмена запрещает новые запросы. Каждый успешный пакет сохраняется до следующей передачи. После сбоя/перезапуска новое согласие охватывает только ещё пустые встречи — сохранённые готовые, ручные и отказные ответы не пересылаются автоматически. Не обещать абсолютного отсутствия повторных расходов при потере ответа провайдера до сохранения.

В том же общем редакторе добавлены автосохранение ручной работы, явная кнопка сохранения, восстановление черновика, подготовка пустых диалогов через ИИ, остановка запросов и отдельное одобрение перед сборкой. Двойной клик блокируется до первого await. Повторный вход не восстанавливает согласие на облако или установку.
