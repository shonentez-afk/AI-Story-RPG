## Активная разработка: M2h7c3

Ветка feature/m2h7c3-reviewed-prose-bookworld-overlay-20261105. Новый ReviewedProseSceneApproval требует явного прочтения всего черновика и осознания вымышленного статуса. ReviewedProseSceneOverlay привязывает принятую прозу к конкретной редакции книги, финальному StoryPlan, сцене, маршруту, digest и SHA текста. MultiActTrialCompiler теперь умеет включить такой текст в НОВЫЙ частный BookWorld, сохраняя дословные цитаты, provenance, исходные действия, флаги, условия, предметы и SQLite. Без одобрения — обычная техническая сцена. Страница preview возвращает выбранную прозу в MultiActTrialPage; пользователь может убрать её до сборки. При включении отдельного правила второго акта прежний digest отклоняется; UI не даёт смешивать разные планы.

Код и тесты добавлены В ВЕТКЕ. Нельзя считать готовым без exact-head CI/M0, проверки ZIP и двух маршрутов, merge и post-merge релиза. Принятие прозы пользователем не равно независимой литературной экспертизе; новые сведения NPC и предметы из текста не становятся исполняемыми фактами.

## Остаётся до полноценной RPG

1. Пакетная генерация художественного текста для всех сцен, с единым согласованным списком цитат, лимитом платных запросов и checkpoints, без обязательных десятков ручных подтверждений.
2. Настоящая литературная проверка событий, NPC, обещаний, вещей, времени и обеих сюжетных веток, затем корректировка текста на основе ошибок.
3. Полноценные CANON и ALTER_FATE, действительно разные концовки, простой путь «Добавить книгу → режим → подготовить → играть».
4. Реальный контролируемый GLM E2E на «Короле-лягушонке» плюс второй книге, затем Windows/Android ручное испытание и возобновление сохранений.
5. Совместимо расширить model_provenance: private .bworld v2 пока требует provider=none/model_id=null даже при предварительном использовании ИИ. Это не доказательство отсутствия ИИ и не достоверная история происхождения текста.

Никаких чужих FB2, ключей и ответов из личных книг в публичный репозиторий; никаких облачных запросов без явного согласия; не переписывать прежние кампании.
