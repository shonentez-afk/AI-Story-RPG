## Новый единый пакет: ИИ-реплики + восстановление редактора + прежняя автономная сборка

Статус нового кода: направляется на CI; результаты требуется проверить по точному новому SHA.

В общий экран нескольких NPC подключён авторский сервис Z.ai через существующие AiCloudPreferences, защищённый AiApiKeyVault, ZaiModel и AiHttpTransport. Подготовка идёт только после отдельного просмотра точных отправляемых цитат, личностей, игровых условий и числа запросов. Открытие редактора не делает POST. ИИ получает только выбранные пустые встречи, не ключи/сохранения/полную книгу и не готовые ручные реплики. Он не может поменять character_id, состав встреч, зависимости или правила игры. Ответ — непроверенный текст или явный отказ от предложения, а не авторитетный канон.

NpcWritingStore сохраняет выбранные встречи, обе реплики, зависимости и неопределённость в отдельной приватной папке через существующую atomic checkpoint repository. API-ключи, исходные цитаты, сырые HTTP ответы и разрешения на облако/установку не сохраняются. Источник, план и карточки проверяются по SHA. При повреждении файл остаётся нетронутым, удаление требует явного подтверждения. Ревизии предотвращают перезапись из другого окна. Сохранение производится до показа успешного прогресса.

Каждый полученный пакет ИИ сохраняется отдельно. 429/сбой соединения допускают до трёх попыток с теми же байтами; квота/ключ/неправильный JSON не вызывают слепых повторов. Отмена останавливает новые передачи. После сбоя/перезапуска уже готовые, ручные и явно пропущенные моделью встречи не отправляются повторно; продолжение требует нового согласия. Один параллельный платный пакет на редакцию кампании.

Редактор сохраняет ручные изменения, поддерживает возвращение после закрытия, предлагает подготовить пустые диалоги через ИИ и затем требует отдельной проверки/одобрения пакета перед сборкой прежним BookwideNpcCampaignAuthoring. Игровой движок не зависит от сервиса ИИ.

Новый npc_campaign_writing_test.dart: приватное сохранение/перезапуск, повреждённые согласования, ошибка записи, конкурирующие ревизии, отсутствие разрешения/ключа, поддельный NPC, частичный 429 + возобновление без повтора готового, отмена, refusal, сохранность ручных правок и полный mock-GLM → human review → rich-v3 → SQLite.
