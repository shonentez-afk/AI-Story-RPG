## Следующая активная реализация — M2h7

**В работе [PR #81](https://github.com/shonentez-afk/AI-Story-RPG/pull/81), M2h7a.** Уже добавлены новый типизированный `SourceBoundBridgeAuditor`, независимая перепроверка обеих буквальных цитат, отличение сообщения NPC от факта мира, запрет подмены редакции/утверждений/цитат, диагностика порядка ТЕКСТА и маркировка `GAME_FICTION`. Новый аудитор подключён к `MultiActTrialCompiler` для всех переходов между актами: он не может превратить формальную проверку в литературный канон. Добавлены негативные Dart-тесты на чужую книгу, недостоверные цитаты, неподтверждённые свидетельства и сообщения персонажей. **Результаты exact-head CI для PR #81 перепроверять перед слиянием: сам факт наличия кода ещё не значит, что он принят.** Модуль НЕ является полноценной проверкой художественного смысла; дальнейшая M2h7b всё ещё требуется.

Сначала доказуемая литературная причинность и безопасная атрибуция сведений по исходным цитатам, потом художественные сцены и полноценные CANON/ALTER_FATE. Техническая спецификация и тесты: [M2H7_LITERARY_VALIDATION_ACCEPTANCE_RU_2026-11-05.md](docs/M2H7_LITERARY_VALIDATION_ACCEPTANCE_RU_2026-11-05.md).

Нельзя автоматически объявлять вымышленный переход каноном; цитата подтверждает текст, но не истинность утверждений персонажа, знания NPC, владение предметом или мировой порядок флешбеков. Следующий этап должен работать без hardcode «Король-лягушонок» и сохранять fail-closed при нехватке доказательств. Реальный GLM E2E не эквивалентен mock тесту и требует отдельного контролируемого согласия/бюджета.

**Итоговая цель пользователя:** «Добавить книгу → выбрать режим → подготовить → играть» без обязательных технических редакторов, с достоверной, связной альтернативной линией, сохранением, Windows/Android и без повторных скрытых облачных запросов. Пока есть только пробная адаптация, НЕ полная игра по произвольной книге.

Нельзя публиковать закрытые FB2 или API ключи в CI, переписывать старые кампании, запускать облачный POST без явного согласия и утверждать художественную готовность по зелёному CI. Проверку источника вести на общественном достоянии, права конкретного перевода проверять отдельно.
