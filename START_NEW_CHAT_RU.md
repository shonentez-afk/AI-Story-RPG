## Новый единый пакет: сценарий с несколькими NPC

Статус: НАПРАВЛЯЕТСЯ НА CI; успешность нового кода ещё не подтверждена.

- `WholeBookNpcSourcePlan` включает все доступные source events существующего многоактного сценария, не обрезает их молча. Недостающие акты/главы явно остаются пробелами покрытия. Предельный объём v3 и причинного обхода не повышен.
- `BookwideNpcCampaignAuthoring` ищет пары проверенных упоминаний по всему включённому сценарию и по всем подтверждённым карточкам NPC. Это предложения частных игровых встреч, не утверждение авторской хронологии. Встречи могут находиться в разных актах.
- Каждая встреча имеет собственные ID факта, памяти и действий; имя не заменяет постоянный `character_id`. Один NPC может иметь несколько независимых встреч. Начало поздней встречи может требовать фактически состоявшуюся раннюю встречу другого NPC, без передачи чужих знаний.
- Один неизменяемый review связывает точные байты базовой игры, цитаты, карточки, реплики и зависимости. Перед сборкой карточки перечитываются. Изменение текста/личности/предшественника аннулирует согласие.
- `ReviewedNpcCampaignBookworldWriter` переводит принятый пакет в существующие `learn_fact` / `knows_fact`, `NpcSocialRulebook` и подписанные `scene_dialogue_knowledge`. Формат `.bworld` не меняется. Старые действия сохраняются; новый глобальный проход через реальный `StoryWorld` обязан подтвердить все ранее доступные и все новые действия. Тупик, недостижимая встреча, цикл зависимостей или превышение бюджета — отказ, не частичный успех.
- В существующем редакторе добавлена одна точка входа «События книги и несколько NPC». Проверенный расширенный редактор без изменения его содержимого перенесён в `multi_act_trial_editor.dart`; публичный `MultiActTrialPage` сохраняет прежние параметры и открывает общий экран кампании. Это не новая библиотека книг или второй runtime.
- Новый E2E `bookwide_npc_campaign_test.dart`: синтетическая русская книга, 12 событий / 3 акта / 3 постоянных NPC, причинная цепочка встреч, ветка пропуска, скрытие неразрешённой реплики, раздельные знания, направленное доверие, строгий ZIP-импорт, SQLite reopen, воспроизведение журнала. Отдельно — устаревшее согласие, отозванные карточки, подменённая цитата, неизвестные поля и циклические зависимости. Открытие UI не должно делать API-запросов или устанавливать игру.
