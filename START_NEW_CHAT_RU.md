## Принятый в CI единый пакет нескольких NPC

Подробная приёмка: [P0_MULTI_NPC_CAMPAIGN_ACCEPTANCE_RU_2026-11-07.md](docs/P0_MULTI_NPC_CAMPAIGN_ACCEPTANCE_RU_2026-11-07.md). Текущий статус: [CURRENT_STATUS_RU.md](docs/CURRENT_STATUS_RU.md).

`WholeBookNpcSourcePlan` включает все доступные дополнительные source events существующего многоактного сценария без молчаливого обрезания. Недостающие акты/главы остаются явно указанными пробелами. Ограничения формата и причинного обхода не повышены.

`BookwideNpcCampaignAuthoring` ищет пары проверенных упоминаний по всему включённому сценарию и всем переданным подтверждённым NPC-карточкам. Это предложения частных игровых встреч, не авторская хронология. У каждой встречи собственные fact/memory/choice IDs, у персонажа постоянный character_id. Начало поздней встречи может требовать действительно выполненное первое действие ранней встречи другого NPC, не копируя чужое знание. Требование завершить ответную реплику — иная семантика, пока не реализованная этим условием.

Неизменяемое согласование связывает точные байты базовой игры, карточки, цитаты, реплики и зависимости. Перед сборкой карточки перечитываются, изменения отзывают старое согласие. `ReviewedNpcCampaignBookworldWriter` переводит пакет в прежние learn_fact / knows_fact / NpcSocialRulebook / scene_dialogue_knowledge. Все прежние доступные и все новые действия проходят реальный StoryWorld. Тупик, недостижимое действие, цикл зависимостей или превышение бюджета блокируют сборку. Новый мир получает отдельный bookworld_id, прежние сохранения не переписываются.

В существующем редакторе есть один вход «События книги и несколько NPC». Содержимое прежнего расширенного редактора перенесено без изменений в multi_act_trial_editor.dart. Новый экран не создаёт второй runtime/библиотеку и при открытии не вызывает API или установку игры.

E2E `bookwide_npc_campaign_test.dart`: синтетический русский источник, 12 событий / 3 акта / 3 NPC, причинная цепочка встреч, пропуск знакомства, скрытая условная реплика, раздельные знания, память и направленное доверие, strict ZIP import, SQLite close/reopen, hash-chain replay. Отрицательные случаи: устаревшее согласие, отозванные карточки, подменённая цитата даже с пересчитанным SHA, неизвестные поля, неверный NPC ID и циклы зависимостей. ## Ограничения: НЕ объявлять проект завершённым

Новый общий экран использует готовый многоактный черновик и свободного игрока. Выбранная литературная роль героя остаётся в прежнем редакторе и ещё не объединена с этим пакетом. Реплики вводятся и одобряются вручную; автоматическое содержательное написание всей книги через GLM в новый экран не подключено. Осмысленность сюжетов и литературный канон не доказаны синтетическими тестами.

Сборщик принимает player-only базу без ранее подписанных NPC-диалогов и не объединяет молча старую одно-NPC ветку. Технические пределы: до 32 эпизодов, 15 NPC, 64 фактов и 16 действий на сцену, плюс прежние бюджеты обхода. Максимальная нагрузка и несколько эпизодов одного NPC этим E2E отдельно не проверены.

Полноценные CANON / ALTER_FATE, живой GLM, две разные реальные приватные RU FB2 и физический QA Android/Windows ещё нужны для общей приёмки #118. Issue #118 не закрывать по одному зелёному CI.
