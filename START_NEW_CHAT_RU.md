## Текущая разработка: M2h7c1

Ветка feature/m2h7c-source-locked-prose-preview-20261105. Новый ZaiSourceLockedProsePreviewService готовит GLM-предложение **одной** сцены StoryPlan. Привязка к изданию/ситуации/точной цитате, локальный digest разрешённого пользовательского контекста, защищённый BYOK-ключ, проверка JSON и ID, обрыв/429 с максимум тремя попытками одного и того же запроса. Результат — непринятый художественный текст, не новое правило, не канон, не установленная игра. Для этой ветки тесты только подготовлены; **не считать пройденными до exact-head CI**. [Описание ограничений](docs/M2H7C1_SOURCE_LOCKED_PROSE_RU.md).

Этот первый шаг намеренно не отправляет ничего автоматически, не добавляет экран и не пишет прозу в BookWorld. Для реального пользовательского сценария следующим этапом необходимо показать контекст в UI, получить отдельное согласие, сохранить подтверждённый checkpoint, сверить художественный текст с флагами/NPC и только затем встроить его в существующий приватный компилятор.

## Оставшиеся задачи до первого полноценного MVP

1. Источник-специфическая смысловая проверка причинных мостов, знаний персонажей, вещей и надёжности текста; не обещать универсальное понимание по двум цитатам.
2. Автоматическая генерация связной художественной прозы, диалогов, мотивов и последствий ПО ВСЕМ выбранным сценам с частными checkpoint и лимитом затрат GLM.
3. Настоящие режимы CANON и ALTER_FATE, которые согласованы с движком, импортом и сохранениями. Проверка отдельных решений и действительно разных концовок, без несуществующих обещаний.
4. Простой UX «Загрузить книгу → режим и роль → подготовить → играть», без обязательных технических редакторов; показывать цену/согласие/прогресс.
5. Реальные GLM E2E и литературная оценка на законно используемом «Короле-лягушонке» + второй другой книге; Windows/Android device QA и восстановление кампании. Потом EPUB, романы и расширенные свободные действия.

**Запреты:** не передавать чужие закрытые FB2, ключи и личные ответы модели в GitHub/CI; не вызывать облачный POST без отдельного согласия; не править старые сохранения; не считать зелёный CI доказательством литературного качества.
