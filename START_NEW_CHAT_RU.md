## Что действительно объединено

Выбранный герой → source-bound предметы/факты → несколько NPC → единый строгий импорт → реальная проверка игровых путей → автономная SQLite-кампания. Использованы старые WholePlanGameplayBatchPage и ReviewedGameplayCompiler, а не новый движок.

`NpcCampaignConsequences` привязывает согласие на эффекты к точным байтам базы, плану и выбранному герою. Новый пункт «Предметы и последствия» в общем редакторе показывает каждое действие, требует отдельного согласия, позволяет отказаться. Изменение эффектов отзывает финальное согласие на NPC-кампанию. Перед установкой она перепроверяется для активного архива. Исходная игра и старые сохранения не изменяются.

Устранено прежнее взаимное исключение gameplay_review и npc_knowledge. Импортёр теперь принимает только строгое объединение независимо доказанных эффектов: ordinary review для предметов/знаний player, полный NPC-review для точного scene/choice/actor/fact. Неучтённый эффект, чужая цитата или актёр остаются ошибкой. Обновлены native Dart и независимый Python reference в tools/bookworld; внешний E6d не трогали. Поля v3 те же, но новый совместный мир требует обновлённого импортёра.

Сквозной тест: Артем как герой → наблюдение/воспоминание → получение ключа → SQLite close/reopen с ключом → расходование → две другие NPC-встречи → финал / hash replay. Ветка отказа не получает предмет. Отрицательные проверки защищают источники, роли, согласия и байты архива. Прежний проблемный узкий UI-тест выбора Марии теперь проверяет реальный интерактивный элемент, сохранённую ревизию и видимый заголовок; он прошёл. Четыре новых Dart-теста и пять Python-тестов проверяют комбинированные согласования; настоящий Dart ZIP/SQLite дополнительно принимается независимым Python verify.

Подробности и границы: [P0_COMPOSED_HERO_ITEMS_NPC_RU.md](docs/P0_COMPOSED_HERO_ITEMS_NPC_RU.md).

## Ограничения, которые нельзя скрывать

Согласованный набор эффектов пока не восстанавливается автоматически после закрытия общего редактора: выбор/согласие повторяются по сохранённым предложениям. Роль и реплики сохраняются отдельно как прежде. Генератор реплик не получает автоматически сведения о фактическом владении предметом; проверка мотивов/смысла остаётся авторской. Не объявлять её выполненной только потому, что предмет работает.

Не завершены автоматическая содержательная адаптация всей произвольной книги, литературная причинность/хронология, CANON/ALTER_FATE, живой GLM, две разные реальные приватные русские FB2 и физический QA Windows/Android. #118 остаётся OPEN.
