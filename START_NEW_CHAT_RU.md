## Новый пакет — сохранённая авторская редакция

В этом кодовом изменении добавлен `NpcCampaignConsequenceStore`, подключённый в существующий `WholeBookNpcCampaignPage`, и `npc_campaign_author_revision_test.dart`. Итог новых CI ещё нужно проверить по точному кодовому SHA; не выдавать наличие тестов за их успешный запуск.

Сохраняются только выбранные эффекты, их source/event/choice-ссылки и пояснения автора. Существующие герой и NPC-реплики хранятся прежними механизмами. Восстановление заново строит manifest и вызывает прежний строгий preview/reachability compiler на текущей книге и базовом архиве. Согласия на облако, применение эффектов и установку не сохраняются. Пользователь видит «Проверить сохранённые эффекты», а не выбирает их заново и не запрашивает ИИ повторно.

Выбор связан с source/plan/hero/base; конкурентная запись проверяет ревизию и точные байты записи. Сброс оставляет tombstone с новым write_id, поэтому старое окно не может вернуть удалённый выбор. Повреждение блокирует сборку без автоматического обнуления; отдельный подтверждённый сброс касается только предметного выбора. Перед итоговой проверкой и установкой повторно сверяются герой, сохранённые реплики/карточки и эффекты. Новая редакция в другом окне отзывает старое итоговое согласие.

Автономный runtime один: story_core / rich-v3 / SQLite. Движок, wire-схема, E6d и main не изменяются. Полный отчёт и границы: [P0_DURABLE_AUTHOR_REVISION_RU.md](docs/P0_DURABLE_AUTHOR_REVISION_RU.md). [Текущий статус](docs/CURRENT_STATUS_RU.md). Генератор реплик по-прежнему получает только явно показанный контекст; он не знает автоматически фактический инвентарь разных ветвей. Следующий содержательный блок — явно согласованный, привязанный к маршрутам контекст последствий/мотиваций для ИИ и проверка согласованности реплик. Нельзя выдавать выбранный grant_item за уже полученную вещь.

Остаются автоматическая содержательная адаптация всей произвольной книги, литературная хронология/причинность, CANON/ALTER_FATE, живой GLM, две разные реальные приватные русские FB2, физический QA Windows/Android. #118 не закрывать по синтетическим тестам.
